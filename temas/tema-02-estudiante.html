🩸 ¿Cuál es el grupo sanguíneo más común?

Rincón (2017) presenta el caso real de 80 personas clasificadas por su grupo sanguíneo: A, B, AB u O. ¿Cuál creen que es el más común? ¿Y en este salón?

Antes de seguir: ordena de más a menos común los grupos A, B, AB, O según tu intuición. ¿Cuántos compañeros crees que coinciden contigo en su tipo de sangre?

🔬 Exploremos: construyendo una tabla a mano

Respondan en el salón: ¿cuál es su medio de transporte habitual a la universidad? Cuenten cuántas personas cayeron en cada categoría y arme su propia tabla de frecuencias — sin fórmulas todavía, solo contando.

Cuando terminen de contar: ¿alguien calculó también el porcentaje sin que se lo pidieran? Esa es exactamente la idea de frecuencia relativa, y ya la usaron de forma intuitiva.

TipPregunta guía

¿Todos los grupos del salón llegaron al mismo total? ¿Debería coincidir?

🎛️ Simulación: barras vs. pastel

Con los datos de grupo sanguíneo de Rincón (A: 15%, B: 35%, AB: 20%, O: 30%, de 80 personas), compara las dos formas de representarlo.

Code 
f <- c(15, 35, 20, 30)
gs <- c("A", "B", "AB", "O")

barplot(f, names.arg = gs, col = "#004B85",
        xlab = "Grupo sanguíneo", ylab = "Frecuencia porcentual",
        main = "Gráfica de barras")

pie(f, labels = paste0(gs, " (", f, "%)"),
    col = c("#004B85", "#4B8BC2", "#FFB903", "#D9DEE4"),
    main = "Gráfica de pastel")
NoteLo que deberías notar

Con solo 4 categorías, ambas gráficas comunican bien. Prueba (en tu propia sesión de R) qué pasa si conviertes f y gs en 9 o 10 categorías en vez de 4 — el pastel se vuelve difícil de leer, mientras que las barras siguen siendo claras.

💡 Discusión

  • ¿En qué momento el pastel dejó de ser útil al aumentar las categorías?
  • ¿Cambiaría algo si reordenas las barras de A, B, AB, O a B, O, AB, A? ¿Debería importar, siendo una variable nominal?
  • Si solo te dieran los porcentajes (15%, 35%, 20%, 30%) sin decirte que son 80 personas, ¿qué no podrías calcular?

📖 Ahora sí, la teoría

  • Frecuencia absoluta
  • Frecuencia relativa
  • Frecuencia relativa porcentual
  • Frecuencia acumulada (solo ordinales)

El número de veces que se observa una categoría. Notación (Rincón, 2017): si \(C_1, C_2, \dots, C_k\) son las categorías, sus frecuencias absolutas se denotan \(f_1, f_2, \dots, f_k\). En el ejemplo: 28 personas tienen grupo B.

La frecuencia absoluta dividida entre el total de observaciones \(n\) — un número entre 0 y 1: \(f_i / n\). Para el grupo B: 28/80 = 0.35. La suma de todas las frecuencias relativas siempre es 1.

La frecuencia relativa multiplicada por 100: \(100 \cdot f_i/n\). Para el grupo B: 35%.

Cuando las categorías tienen un orden natural \(C_1 \le C_2 \le \dots \le C_k\), la frecuencia acumulada de \(C_j\) es la suma de su frecuencia y las de todas las categorías anteriores: \(f_1 + f_2 + \dots + f_j\). Solo tiene sentido si la variable es ordinal — no aplica a grupo sanguíneo, que es nominal (no hay “categoría anterior” bien definida).

Ejemplo completo con frecuencia acumulada

A diferencia del grupo sanguíneo (nominal), tomemos una variable ordinal: el nivel de satisfacción de 46 encuestados, con niveles Bajo < Medio < Alto (ejemplo adaptado de Rincón, 2017).

Code 
nivel <- c("Bajo", "Medio", "Alto")
f_abs <- c(15, 21, 10)

tabla <- data.frame(
  Nivel = nivel,
  Frec_absoluta = f_abs,
  Frec_acumulada = cumsum(f_abs),
  Frec_relativa = round(f_abs / sum(f_abs), 3),
  Frec_rel_acumulada = round(cumsum(f_abs) / sum(f_abs), 3)
)
knitr::kable(tabla)
NoteLo que deberías notar

La frecuencia acumulada de “Alto” (46) coincide con el total — tiene que ser así, porque acumula todas las categorías. Prueba reordenar nivel a c("Alto", "Bajo", "Medio") y correr el chunk de nuevo: la frecuencia acumulada deja de tener sentido, porque rompiste el orden natural de la variable.

Las dos gráficas

  • Gráfica de barras
  • Gráfica de pastel

Una barra por categoría, cuya altura es la frecuencia. Sirve para nominales y ordinales; en las nominales, el orden de las barras es arbitrario.

Cada categoría es una porción de un círculo, proporcional a su frecuencia relativa. Comunica bien “parte de un todo”, pero pierde claridad con muchas categorías.

Tip💡 Truco de interpretación

Si te muestran una tabla con solo porcentajes (sin el total de observaciones, n), no puedes verificar ni comparar nada con seriedad — un 60% de 5 personas y un 60% de 5.000 comunican una certeza completamente distinta. Pide siempre el n antes de interpretar un porcentaje. Ver más trucos →

🛠️ Cuatro maneras de hacerlo en R

El mismo resultado — tabla de frecuencias y gráfica — se puede lograr de cuatro formas distintas. Conocer las cuatro te da alternativas según el contexto: la manual te enseña qué calcula R por dentro, la de R base es la más rápida para explorar, tidyverse es la más legible cuando encadenas varios pasos de análisis, y ggplot2 es la más flexible para gráficos de calidad profesional.

  • Manera 1 · Construcción manual
  • Manera 2 · Funciones de R base
  • Manera 3 · tidyverse (dplyr)
  • Manera 4 · ggplot2

Sin table(): construyes la tabla componente por componente, exactamente como se hace a mano. Ideal para entender qué significa cada columna.

Code 
# Datos: grupos sanguíneos (frecuencias observadas de 80 personas)
categorias <- c("A", "B", "AB", "O")
f_abs <- c(12, 28, 16, 24)
n <- sum(f_abs)

tabla_manual <- data.frame(
  Categoria       = categorias,
  Frec_absoluta   = f_abs,
  Frec_relativa   = f_abs / n,
  Frec_porcentual = 100 * f_abs / n
)
tabla_manual
  Categoria Frec_absoluta Frec_relativa Frec_porcentual
1         A            12          0.15              15
2         B            28          0.35              35
3        AB            16          0.20              20
4         O            24          0.30              30

La gráfica también se puede construir “a mano”, pasándole directamente los vectores a barplot():

Code 
barplot(f_abs, names.arg = categorias, col = "#004B85", border = "white",
        xlab = "Grupo sanguíneo", ylab = "Frecuencia absoluta",
        main = "Construcción manual")

Cuando tienes los datos crudos (una observación por persona, no las frecuencias ya contadas), table() hace el conteo por ti:

Code 
set.seed(1)
# Simulamos los 80 registros individuales a partir de las proporciones
sangre <- sample(c("A","B","AB","O"), 80, replace = TRUE,
                 prob = c(0.15, 0.35, 0.20, 0.30))

tabla_base <- table(sangre)
tabla_base
sangre
 A AB  B  O 
12 20 24 24
Code 
prop.table(tabla_base)          # frecuencia relativa
sangre
   A   AB    B    O 
0.15 0.25 0.30 0.30
Code 
prop.table(tabla_base) * 100    # frecuencia porcentual
sangre
 A AB  B  O 
15 25 30 30
Code 
barplot(tabla_base, col = "#004B85", border = "white", main = "barplot()")
pie(tabla_base, col = c("#004B85","#4B8BC2","#FFB903","#D9DEE4"), main = "pie()")

Con datos crudos, count() hace lo mismo que table() pero devuelve un data frame que se puede seguir transformando con %>%/|> — útil cuando la tabla de frecuencias es solo un paso intermedio de un análisis más largo:

Code 
library(tidyverse)

datos_sangre <- data.frame(grupo = sangre)

tabla_tidy <- datos_sangre |>
  count(grupo, name = "Frec_absoluta") |>
  mutate(
    Frec_relativa   = Frec_absoluta / sum(Frec_absoluta),
    Frec_porcentual = round(100 * Frec_relativa, 1)
  )
tabla_tidy
  grupo Frec_absoluta Frec_relativa Frec_porcentual
1     A            12          0.15              15
2    AB            20          0.25              25
3     B            24          0.30              30
4     O            24          0.30              30

count() agrupa y cuenta en un solo paso (es un atajo de group_by() |> summarise(n = n())), y como el resultado es un data frame normal, mutate() puede agregar directamente las columnas de frecuencia relativa y porcentual sin pasos manuales aparte.

ggplot2 cuenta las frecuencias automáticamente con geom_bar() cuando le das los datos crudos (el mismo data frame datos_sangre de la pestaña anterior). Es el estándar para gráficos publicables:

Code 
library(ggplot2)

ggplot(datos_sangre, aes(x = grupo, fill = grupo)) +
  geom_bar() +
  scale_fill_manual(values = c("#004B85","#4B8BC2","#FFB903","#D9DEE4")) +
  labs(x = "Grupo sanguíneo", y = "Frecuencia", title = "geom_bar()") +
  theme_minimal() +
  theme(legend.position = "none")

Y el “pastel” en ggplot2 es una barra apilada llevada a coordenadas polares (la misma técnica que usa el laboratorio del curso):

Code 
ggplot(datos_sangre, aes(x = "", fill = grupo)) +
  geom_bar(width = 1) +
  coord_polar("y") +
  scale_fill_manual(values = c("#004B85","#4B8BC2","#FFB903","#D9DEE4")) +
  labs(x = NULL, y = NULL, title = "geom_bar() + coord_polar()") +
  theme_void()
Tip¿Cuál usar?
  • Manual cuando el enunciado te da las frecuencias ya contadas (como en muchos ejercicios de Rincón), o cuando quieres verificar a mano lo que hace R.
  • R base (table()) para exploración rápida en la consola.
  • tidyverse (count()) cuando la tabla de frecuencias es un paso dentro de un análisis más largo (filtrar, agrupar por otra variable, graficar después) — se encadena naturalmente con %>%/|>.
  • ggplot2 para informes y trabajos finales — permite personalizar todo y combina con el resto del tidyverse.

Lo mismo, pero con una variable cuantitativa discreta

Todo lo anterior también aplica a una variable cuantitativa discreta con pocos valores distintos — la única diferencia es que, al haber un orden numérico real, la frecuencia acumulada sí tiene sentido (a diferencia del grupo sanguíneo, que es nominal).

Enunciado: en un centro médico se registra la cantidad de pacientes que ingresan por consulta externa durante 30 días:

1, 1, 2, 0, 0, 5, 1, 2, 3, 4, 1, 1, 2, 2, 3, 4, 4, 3, 2, 0,
0, 1, 2, 2, 3, 4, 4, 5, 0, 1
Code 
pacientes <- c(1,1,2,0,0,5,1,2,3,4,1,1,2,2,3,4,4,3,2,0,
               0,1,2,2,3,4,4,5,0,1)

f_abs <- table(pacientes)
tabla_pacientes <- data.frame(
  Pacientes         = as.numeric(names(f_abs)),
  Frec_absoluta     = as.vector(f_abs),
  Frec_acumulada    = cumsum(as.vector(f_abs)),
  Frec_relativa     = round(as.vector(f_abs) / length(pacientes), 2),
  Frec_rel_acumulada = round(cumsum(as.vector(f_abs)) / length(pacientes), 2)
)
tabla_pacientes
  Pacientes Frec_absoluta Frec_acumulada Frec_relativa Frec_rel_acumulada
1         0             5              5          0.17               0.17
2         1             7             12          0.23               0.40
3         2             7             19          0.23               0.63
4         3             4             23          0.13               0.77
5         4             5             28          0.17               0.93
6         5             2             30          0.07               1.00

El valor más frecuente es 1 y 2 pacientes por día (7 días cada uno, empatados). La frecuencia relativa acumulada hasta “2 pacientes” es 0.63 — es decir, en el 63% de los 30 días se atendieron 2 pacientes o menos. Esa lectura acumulada solo tiene sentido porque la variable es cuantitativa (hay un “menos que” real entre 1 y 2 pacientes) — no la podrías hacer con el grupo sanguíneo del ejemplo anterior.

✅ Ejercicios autocorregibles

Ejercicio 1 — Completa el código

# ¿Cómo obtienes la frecuencia relativa porcentual de una tabla?
___(table(datos)) * 100
Ver respuesta prop.table(table(datos)) * 100 — convierte las frecuencias absolutas en proporciones antes de multiplicar por 100.

Ejercicio 2 — Verdadero o falso

1. La frecuencia relativa siempre está entre 0 y 1.
2. La gráfica de pastel es mejor que la de barras cuando hay muchas categorías.
3. La frecuencia acumulada tiene sentido para variables nominales.

🗂️ Resumen

  • Una tabla de frecuencias puede expresarse como absoluta, relativa o porcentual — y siempre conviene reportar el total (n).
  • La gráfica de barras funciona para nominales y ordinales; el pastel comunica proporciones pero se degrada con muchas categorías.
  • Solo las variables ordinales admiten frecuencia acumulada, porque solo ellas tienen un orden natural entre categorías.

## 📖 Ahora sí, la teoría

::: {.panel-tabset}

## Frecuencia absoluta
El número de veces que se observa una categoría. Notación (Rincón, 2017): si $C_1, C_2, \dots, C_k$ son las categorías, sus frecuencias absolutas se denotan $f_1, f_2, \dots, f_k$. En el ejemplo: 28 personas tienen grupo B.

## Frecuencia relativa
La frecuencia absoluta dividida entre el total de observaciones $n$ — un número entre 0 y 1: $f_i / n$. Para el grupo B: 28/80 = 0.35. La suma de todas las frecuencias relativas siempre es 1.

## Frecuencia relativa porcentual
La frecuencia relativa multiplicada por 100: $100 \cdot f_i/n$. Para el grupo B: 35%.

## Frecuencia acumulada (solo ordinales)
Cuando las categorías tienen un orden natural $C_1 \le C_2 \le \dots \le C_k$, la frecuencia acumulada de $C_j$ es la suma de su frecuencia y las de todas las categorías anteriores: $f_1 + f_2 + \dots + f_j$. **Solo tiene sentido si la variable es ordinal** — no aplica a grupo sanguíneo, que es nominal (no hay "categoría anterior" bien definida).

:::

### Ejemplo completo con frecuencia acumulada

nivel <- c("Bajo", "Medio", "Alto")
f_abs <- c(15, 21, 10)

tabla <- data.frame(
  Nivel = nivel,
  Frec_absoluta = f_abs,

  Frec_relativa = round(f_abs / sum(f_abs), 3),
  Frec_rel_acumulada = round(cumsum(f_abs) / sum(f_abs), 3)
)
knitr::kable(tabla)
```

)
tabla_manual
```

## Manera 2 · Funciones de R base

Cuando tienes los **datos crudos** (una observación por persona, no las frecuencias ya contadas), `table()` hace el conteo por ti:

```{r}
set.seed(1)
# Simulamos los 80 registros individuales a partir de las proporciones
sangre <- sample(c("A","B","AB","O"), 80, replace = TRUE,
                 prob = c(0.15, 0.35, 0.20, 0.30))

tabla_base <- table(sangre)
tabla_base
prop.table(tabla_base)          # frecuencia relativa
prop.table(tabla_base) * 100    # frecuencia porcentual
```

```{r}
#| layout-ncol: 2
barplot(tabla_base, col = "#004B85", border = "white", main = "barplot()")
pie(tabla_base, col = c("#004B85","#4B8BC2","#FFB903","#D9DEE4"), main = "pie()")
```

## Manera 3 · `tidyverse` (`dplyr`)

Con datos crudos, `count()` hace lo mismo que `table()` pero devuelve un data frame que se puede seguir transformando con `%>%`/`|>` — útil cuando la tabla de frecuencias es solo un paso intermedio de un análisis más largo:

```{r}
#| message: false
library(tidyverse)

datos_sangre <- data.frame(grupo = sangre)

tabla_tidy <- datos_sangre |>
  count(grupo, name = "Frec_absoluta") |>
  mutate(
    Frec_relativa   = Frec_absoluta / sum(Frec_absoluta),
    Frec_porcentual = round(100 * Frec_relativa, 1)
  )
tabla_tidy
```

`count()` agrupa y cuenta en un solo paso (es un atajo de `group_by() |> summarise(n = n())`), y como el resultado es un data frame normal, `mutate()` puede agregar directamente las columnas de frecuencia relativa y porcentual sin pasos manuales aparte.

## Manera 4 · ggplot2

`ggplot2` cuenta las frecuencias automáticamente con `geom_bar()` cuando le das los datos crudos (el mismo data frame `datos_sangre` de la pestaña anterior). Es el estándar para gráficos publicables:

```{r}
#| message: false
library(ggplot2)

ggplot(datos_sangre, aes(x = grupo, fill = grupo)) +
  geom_bar() +
  scale_fill_manual(values = c("#004B85","#4B8BC2","#FFB903","#D9DEE4")) +
  labs(x = "Grupo sanguíneo", y = "Frecuencia", title = "geom_bar()") +
  theme_minimal() +
  theme(legend.position = "none")
```

Y el "pastel" en ggplot2 es una barra apilada llevada a coordenadas polares (la misma técnica que usa el laboratorio del curso):

```{r}
ggplot(datos_sangre, aes(x = "", fill = grupo)) +
  geom_bar(width = 1) +
  coord_polar("y") +
  scale_fill_manual(values = c("#004B85","#4B8BC2","#FFB903","#D9DEE4")) +
  labs(x = NULL, y = NULL, title = "geom_bar() + coord_polar()") +
  theme_void()
```

::: {.callout-tip}
## ¿Cuál usar?
- **Manual** cuando el enunciado te da las frecuencias ya contadas (como en muchos ejercicios de Rincón), o cuando quieres verificar a mano lo que hace R.
- **R base** (`table()`) para exploración rápida en la consola.
- **`tidyverse` (`count()`)** cuando la tabla de frecuencias es un paso dentro de un análisis más largo (filtrar, agrupar por otra variable, graficar después) — se encadena naturalmente con `%>%`/`|>`.
- **ggplot2** para informes y trabajos finales — permite personalizar todo y combina con el resto del `tidyverse`.
:::

**Paso 2 — Frecuencia relativa porcentual:**

**Paso 3 — Graficarla:**

### Lo mismo, pero con una variable cuantitativa discreta

Todo lo anterior también aplica a una variable **cuantitativa discreta con pocos valores distintos** — la única diferencia es que, al haber un orden numérico real, la frecuencia acumulada sí tiene sentido (a diferencia del grupo sanguíneo, que es nominal).

**Enunciado:** en un centro médico se registra la cantidad de pacientes que ingresan por consulta externa durante 30 días:

```
1, 1, 2, 0, 0, 5, 1, 2, 3, 4, 1, 1, 2, 2, 3, 4, 4, 3, 2, 0,
0, 1, 2, 2, 3, 4, 4, 5, 0, 1
```

```{r}
pacientes <- c(1,1,2,0,0,5,1,2,3,4,1,1,2,2,3,4,4,3,2,0,
               0,1,2,2,3,4,4,5,0,1)

f_abs <- table(pacientes)
tabla_pacientes <- data.frame(
  Pacientes         = as.numeric(names(f_abs)),
  Frec_absoluta     = as.vector(f_abs),
  Frec_acumulada    = cumsum(as.vector(f_abs)),
  Frec_relativa     = round(as.vector(f_abs) / length(pacientes), 2),
  Frec_rel_acumulada = round(cumsum(as.vector(f_abs)) / length(pacientes), 2)
)
tabla_pacientes
```

::: {.ficha-resultado}
El valor más frecuente es 1 y 2 pacientes por día (7 días cada uno, empatados). La frecuencia relativa acumulada hasta "2 pacientes" es 0.63 — es decir, en el 63% de los 30 días se atendieron 2 pacientes o menos. Esa lectura acumulada solo tiene sentido *porque* la variable es cuantitativa (hay un "menos que" real entre 1 y 2 pacientes) — no la podrías hacer con el grupo sanguíneo del ejemplo anterior.
:::

## 🗂️ Resumen

::: {.card-lab}
- Una tabla de frecuencias puede expresarse como absoluta, relativa o porcentual — y siempre conviene reportar el total (n).
- La gráfica de barras funciona para nominales y ordinales; el pastel comunica proporciones pero se degrada con muchas categorías.
- Solo las variables ordinales admiten frecuencia acumulada, porque solo ellas tienen un orden natural entre categorías.
:::

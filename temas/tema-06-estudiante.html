🔩 ¿Cuántos huecos aguanta una broca antes de romperse?

Se probaron 49 brocas idénticas, perforando una aleación de latón hasta que cada una se rompió. Se registró cuántos huecos alcanzó a hacer cada una antes de fracturarse (Contento Rubio). Algunas duraron muchísimo más que las demás.

Antes de ver los datos: si la mayoría de las brocas duran entre 150 y 220 huecos, pero una llegó a 520, ¿esa broca de 520 es simplemente “una muy buena”, o podría tratarse de un dato atípico que merece investigarse aparte?

💡 Discusión

  • ¿Por qué la mediana está más cerca de Q1 que de Q3 en este boxplot? ¿Qué te dice eso sobre la forma de la distribución?
  • Si tuvieras que decidir si estas brocas cumplen un estándar de calidad, ¿usarías la media o la mediana como referencia? ¿Por qué?

📖 Ahora sí, la teoría

  • Cuantiles y cuartiles
  • Rango intercuartílico (RIC / IQR)
  • Vallas y valores atípicos
  • Lectura del boxplot

Un cuantil es un número que separa los datos ordenados en dos partes, según una proporción \(p\): el \(100p\%\) de los datos son menores o iguales al cuantil, y el \(100(1-p)\%\) restante es mayor o igual (Rincón, 2017). Los cuartiles son los cuantiles al 25%, 50% y 75%: - \(Q_1\) (25%): un cuarto de los datos son menores o iguales a este valor. - \(Q_2\) (50%): es la mediana. - \(Q_3\) (75%): tres cuartos de los datos son menores o iguales a este valor.

La altura de la “caja” del boxplot: la distancia entre el primer y tercer cuartil.

\[RIC = Q_3 - Q_1\]

Mide qué tan dispersas están el 50% de las observaciones centrales, sin que le afecten los valores extremos — es una medida de dispersión robusta, análoga a como la mediana es una medida de tendencia central robusta.

Rincón y Contento Rubio coinciden en la misma regla estándar (la que usa boxplot() en R):

\[\text{Brazo superior} = \min\{x_{(n)},\ Q_3 + 1.5 \cdot RIC\}\] \[\text{Brazo inferior} = \max\{x_{(1)},\ Q_1 - 1.5 \cdot RIC\}\]

Los datos que caen fuera de estos brazos se consideran valores atípicos. Contento Rubio añade un segundo nivel: las vallas externas, a \(1.5 \cdot RIC\) más allá de las internas — los datos más allá de esas se consideran atípicos extremos.

  • Si la mediana está centrada en la caja y los bigotes son de largo similar → indicio de simetría.
  • Si la mediana está desplazada hacia un extremo de la caja, o un bigote es mucho más largo que el otro → indicio de sesgo.
  • El ancho de la caja es directamente proporcional a la variabilidad — útil para comparar dos o más boxplots lado a lado.
Tip💡 Truco de interpretación

Un boxplot es excelente para detectar atípicos y comparar dispersión, pero oculta la forma exacta de la distribución: no distingue una distribución unimodal de una bimodal, porque ambas pueden producir una caja parecida. Combínalo siempre con un histograma antes de sacar conclusiones sobre la forma de los datos. Y recuerda: un valor atípico no se elimina automáticamente — primero se investiga su origen. 📐 Guía paso a paso: construir un boxplot a mano

NotePor qué hacerlo a mano al menos una vez

boxplot() te dibuja la caja en una línea, pero en el examen te pueden pedir los cinco números o justificar por qué un dato es atípico. Estos 7 pasos son el procedimiento completo: hazlos con lápiz y papel una vez, y después usa R con la seguridad de saber qué está calculando.

Vamos a construir el boxplot de las 49 brocas, paso por paso.

Paso 1 — Ordenar los datos de menor a mayor

Todo el procedimiento depende del orden. Sin este paso, ningún cuantil tiene sentido:

Code 
duracion <- c(30,118,120,123,125,127,130,136,139,141,155,156,158,159,
              160,160,161,168,170,171,172,174,175,178,178,177,184,185,
              187,191,191,194,197,199,201,206,208,210,211,217,248,263,
              265,270,289,322,388,513,520)

x <- sort(duracion)
n <- length(x)
n
[1] 49
Code 
x
 [1]  30 118 120 123 125 127 130 136 139 141 155 156 158 159 160 160 161 168 170
[20] 171 172 174 175 177 178 178 184 185 187 191 191 194 197 199 201 206 208 210
[39] 211 217 248 263 265 270 289 322 388 513 520

Paso 2 — Localizar la posición de cada cuartil

R usa por defecto esta fórmula para ubicar el cuantil \(p\) dentro de los datos ordenados:

\[h = (n-1)\cdot p + 1\]

donde \(h\) es la posición (no el valor). Con \(n = 49\):

Code 
posicion <- function(p, n) (n - 1) * p + 1

posicion(0.25, n)  # posición de Q1
[1] 13
Code 
posicion(0.50, n)  # posición de Q2 (mediana)
[1] 25
Code 
posicion(0.75, n)  # posición de Q3
[1] 37

Con \(n=49\) las tres posiciones dan números enteros exactos (13, 25 y 37), así que los cuartiles son directamente el dato que ocupa esa posición — no hay que interpolar. Es un caso cómodo: \(n-1 = 48\) es divisible entre 4.

Paso 3 — Leer el valor en esa posición

Code 
Q1 <- x[13]
Q2 <- x[25]
Q3 <- x[37]
c(Q1 = Q1, Q2 = Q2, Q3 = Q3)
 Q1  Q2  Q3 
158 178 208

Y comprobamos que coincide con lo que calcula R directamente:

Code 
quantile(duracion, c(0.25, 0.50, 0.75))
25% 50% 75% 
158 178 208
Important¿Y si la posición no da un número entero?

Con otros valores de \(n\), \(h\) puede caer entre dos datos — por ejemplo, \(h = 12.75\). Entonces se interpola entre el dato 12 y el 13, tomando el 75% del camino entre ellos:

\[Q = x_{(12)} + 0.75\cdot\left(x_{(13)} - x_{(12)}\right)\]

En R esto es automático. En el examen, si te toca a mano, di explícitamente qué método usaste — existen varias convenciones válidas y por eso quantile() y summarytools::descr() a veces difieren en unas décimas.

Paso 4 — Calcular el rango intercuartílico

Code 
ric <- Q3 - Q1
ric
[1] 50
Code 
IQR(duracion)   # la función de R hace lo mismo
[1] 50

Paso 5 — Calcular las vallas

Las vallas internas marcan el límite de los valores atípicos; las externas, el de los atípicos extremos:

Code 
valla_inf <- Q1 - 1.5 * ric
valla_sup <- Q3 + 1.5 * ric
c(valla_inferior = valla_inf, valla_superior = valla_sup)
valla_inferior valla_superior 
            83            283
Code 
ext_inf <- Q1 - 3 * ric
ext_sup <- Q3 + 3 * ric
c(externa_inferior = ext_inf, externa_superior = ext_sup)
externa_inferior externa_superior 
               8              358

Paso 6 — Identificar los valores atípicos

Un dato es atípico si cae fuera de las vallas internas. Ojo: hay que revisar los dos extremos, no solo el superior:

Code 
atipicos <- x[x < valla_inf | x > valla_sup]
atipicos
[1]  30 289 322 388 513 520
Code 
# ¿Cuáles son además atípicos extremos?
x[x < ext_inf | x > ext_sup]
[1] 388 513 520
ImportantCorrección de rigor

Una versión anterior de este material afirmaba que los atípicos eran “289, 322, 388, 513 y 520” — cinco valores, todos por arriba. Faltaba uno: el dato 30 también es atípico, porque cae por debajo de la valla inferior (\(30 < 83\)). Son seis valores atípicos, no cinco.

El error es instructivo: al mirar los datos ordenados, el salto de la cola superior (289 → 520) salta a la vista, mientras que el 30 se ve como “solo el mínimo”. Por eso el criterio de las vallas es una regla, no una impresión visual — y hay que aplicarla a los dos lados siempre. De los seis atípicos, solo 388, 513 y 520 superan además la valla externa (358), así que esos tres son atípicos extremos.

Paso 7 — Determinar dónde terminan los bigotes

Este es el paso que más se malinterpreta: los bigotes no llegan hasta las vallas, sino hasta el dato real más extremo que todavía está dentro de ellas:

Code 
dentro <- x[x >= valla_inf & x <= valla_sup]

bigote_inf <- min(dentro)
bigote_sup <- max(dentro)
c(bigote_inferior = bigote_inf, bigote_superior = bigote_sup)
bigote_inferior bigote_superior 
            118             270

El bigote inferior termina en 118 (no en 83, que es la valla) y el superior en 270 (no en 283). La valla es el criterio para decidir qué es atípico; el bigote se dibuja hasta el último dato que sobrevive ese criterio.

Resumen: los cinco números del boxplot

Code 
c(bigote_inf = bigote_inf, Q1 = Q1, mediana = Q2, Q3 = Q3, bigote_sup = bigote_sup)
bigote_inf         Q1    mediana         Q3 bigote_sup 
       118        158        178        208        270

Y la comprobación definitiva — boxplot() guarda internamente estos mismos valores en $stats:

Code 
b <- boxplot(duracion, plot = FALSE)
b$stats   # bigote inf, Q1, mediana, Q3, bigote sup
     [,1]
[1,]  118
[2,]  158
[3,]  178
[4,]  208
[5,]  270
Code 
b$out     # los valores atípicos que dibuja como puntos sueltos
[1]  30 289 322 388 513 520
Tip💡 Truco de interpretación

boxplot(x, plot = FALSE) es la mejor forma de verificar tus cálculos manuales: te devuelve los cinco números y los atípicos sin dibujar nada. Si tu resultado a mano no coincide con b$stats, revisa el Paso 2 (la fórmula de posición) antes que ninguna otra cosa — ahí es donde se concentran casi todos los errores. Ver más trucos →

El dibujo final, con todo señalado

Code 
boxplot(duracion, horizontal = TRUE, col = "#004B85",
        main = "Duración de 49 brocas: anatomía del boxplot",
        xlab = "No. de huecos antes de romperse")

abline(v = c(valla_inf, valla_sup), col = "#D9534F", lty = 2)
abline(v = c(ext_inf, ext_sup), col = "#B37D00", lty = 3)

legend("topright",
       legend = c("Vallas internas (1.5·RIC)", "Vallas externas (3·RIC)"),
       col = c("#D9534F", "#B37D00"), lty = c(2, 3), bty = "n", cex = 0.8)
NoteLo que deberías notar

Fíjate en la distancia entre la línea roja de la derecha (valla interna, 283) y donde realmente termina el bigote (270): ese espacio vacío es normal y confirma el Paso 7. Y observa que el 30, a la izquierda, queda fuera de su valla roja — es el atípico que se pasa por alto si uno solo mira la cola larga.

Ejercicio 2 — Verdadero o falso

2. Todo punto fuera de los bigotes es necesariamente un error de medición.
3. El rango intercuartílico es Q3 menos Q1.
4. Los bigotes del boxplot se dibujan exactamente hasta las vallas (Q1 − 1.5·RIC y Q3 + 1.5·RIC).

🗂️ Resumen

  • Los cuartiles dividen los datos ordenados en cuatro partes iguales; el RIC mide la dispersión del 50% central, sin verse afectado por valores extremos.
  • El procedimiento completo son 7 pasos: ordenar → posición del cuartil (\(h=(n-1)p+1\)) → leer el valor → RIC → vallas → identificar atípicos → ubicar los bigotes.
  • La regla estándar de valores atípicos usa \(Q_3 + 1.5 \cdot RIC\) y \(Q_1 - 1.5 \cdot RIC\) como límites — y hay que aplicarla a los dos extremos, no solo al que salta a la vista.
  • Los bigotes no llegan hasta las vallas: llegan hasta el último dato real que queda dentro de ellas.
  • Un boxplot resume 5 números (bigote inferior, Q1, mediana, Q3, bigote superior) y hace visibles la mediana, la dispersión y los atípicos en un solo vistazo — sin necesitar el promedio.
  • boxplot(x, plot = FALSE)$stats te devuelve esos cinco números para verificar tus cálculos a mano.

## 📐 Guía paso a paso: construir un boxplot a mano

::: {.callout-note}
## Por qué hacerlo a mano al menos una vez
`boxplot()` te dibuja la caja en una línea, pero en el examen te pueden pedir los cinco números o justificar por qué un dato es atípico. Estos 7 pasos son el procedimiento completo: hazlos con lápiz y papel una vez, y después usa R con la seguridad de saber qué está calculando.
:::

Vamos a construir el boxplot de las 49 brocas, paso por paso.

### Paso 1 — Ordenar los datos de menor a mayor

Todo el procedimiento depende del orden. Sin este paso, ningún cuantil tiene sentido:

```{r}
duracion <- c(30,118,120,123,125,127,130,136,139,141,155,156,158,159,
              160,160,161,168,170,171,172,174,175,178,178,177,184,185,
              187,191,191,194,197,199,201,206,208,210,211,217,248,263,
              265,270,289,322,388,513,520)

x <- sort(duracion)
n <- length(x)
n
x
```

### Paso 2 — Localizar la posición de cada cuartil

R usa por defecto esta fórmula para ubicar el cuantil $p$ dentro de los datos ordenados:

$$h = (n-1)\cdot p + 1$$

donde $h$ es la **posición** (no el valor). Con $n = 49$:

```{r}
posicion <- function(p, n) (n - 1) * p + 1

posicion(0.25, n)  # posición de Q1
posicion(0.50, n)  # posición de Q2 (mediana)
posicion(0.75, n)  # posición de Q3
```

::: {.ficha-resultado}
Con $n=49$ las tres posiciones dan **números enteros exactos** (13, 25 y 37), así que los cuartiles son directamente el dato que ocupa esa posición — no hay que interpolar. Es un caso cómodo: $n-1 = 48$ es divisible entre 4.
:::

### Paso 3 — Leer el valor en esa posición

```{r}
Q1 <- x[13]
Q2 <- x[25]
Q3 <- x[37]
c(Q1 = Q1, Q2 = Q2, Q3 = Q3)
```

Y comprobamos que coincide con lo que calcula R directamente:

```{r}
quantile(duracion, c(0.25, 0.50, 0.75))
```

::: {.callout-important}
## ¿Y si la posición no da un número entero?
Con otros valores de $n$, $h$ puede caer entre dos datos — por ejemplo, $h = 12.75$. Entonces se **interpola** entre el dato 12 y el 13, tomando el 75% del camino entre ellos:

$$Q = x_{(12)} + 0.75\cdot\left(x_{(13)} - x_{(12)}\right)$$

En R esto es automático. En el examen, si te toca a mano, di explícitamente qué método usaste — existen varias convenciones válidas y por eso `quantile()` y `summarytools::descr()` a veces difieren en unas décimas.
:::

### Paso 4 — Calcular el rango intercuartílico

```{r}
ric <- Q3 - Q1
ric

IQR(duracion)   # la función de R hace lo mismo
```

### Paso 5 — Calcular las vallas

Las **vallas internas** marcan el límite de los valores atípicos; las **externas**, el de los atípicos extremos:

```{r}
valla_inf <- Q1 - 1.5 * ric
valla_sup <- Q3 + 1.5 * ric
c(valla_inferior = valla_inf, valla_superior = valla_sup)

ext_inf <- Q1 - 3 * ric
ext_sup <- Q3 + 3 * ric
c(externa_inferior = ext_inf, externa_superior = ext_sup)
```

### Paso 6 — Identificar los valores atípicos

Un dato es atípico si cae **fuera** de las vallas internas. Ojo: hay que revisar **los dos extremos**, no solo el superior:

```{r}
atipicos <- x[x < valla_inf | x > valla_sup]
atipicos

# ¿Cuáles son además atípicos extremos?
x[x < ext_inf | x > ext_sup]
```

::: {.callout-important}
## Corrección de rigor
Una versión anterior de este material afirmaba que los atípicos eran "289, 322, 388, 513 y 520" — cinco valores, todos por arriba. **Faltaba uno:** el dato **30** también es atípico, porque cae por debajo de la valla inferior ($30 < 83$). Son **seis** valores atípicos, no cinco.

El error es instructivo: al mirar los datos ordenados, el salto de la cola superior (289 → 520) salta a la vista, mientras que el 30 se ve como "solo el mínimo". Por eso el criterio de las vallas es una **regla**, no una impresión visual — y hay que aplicarla a los dos lados siempre. De los seis atípicos, solo 388, 513 y 520 superan además la valla externa (358), así que esos tres son atípicos *extremos*.
:::

### Paso 7 — Determinar dónde terminan los bigotes

Este es el paso que más se malinterpreta: **los bigotes no llegan hasta las vallas**, sino hasta el dato real más extremo que todavía está *dentro* de ellas:

```{r}
dentro <- x[x >= valla_inf & x <= valla_sup]

bigote_inf <- min(dentro)
bigote_sup <- max(dentro)
c(bigote_inferior = bigote_inf, bigote_superior = bigote_sup)
```

::: {.ficha-resultado}
El bigote inferior termina en **118** (no en 83, que es la valla) y el superior en **270** (no en 283). La valla es el criterio para decidir qué es atípico; el bigote se dibuja hasta el último dato que sobrevive ese criterio.
:::

### Resumen: los cinco números del boxplot

```{r}
c(bigote_inf = bigote_inf, Q1 = Q1, mediana = Q2, Q3 = Q3, bigote_sup = bigote_sup)
```

Y la comprobación definitiva — `boxplot()` guarda internamente estos mismos valores en `$stats`:

```{r}
b <- boxplot(duracion, plot = FALSE)
b$stats   # bigote inf, Q1, mediana, Q3, bigote sup
b$out     # los valores atípicos que dibuja como puntos sueltos
```

::: {.callout-tip}
## 💡 Truco de interpretación
`boxplot(x, plot = FALSE)` es la mejor forma de **verificar tus cálculos manuales**: te devuelve los cinco números y los atípicos sin dibujar nada. Si tu resultado a mano no coincide con `b$stats`, revisa el Paso 2 (la fórmula de posición) antes que ninguna otra cosa — ahí es donde se concentran casi todos los errores. [Ver más trucos →](../recursos.qmd)
:::

### El dibujo final, con todo señalado

```{r}
#| fig-cap: "Los cinco números y las vallas sobre el boxplot"
boxplot(duracion, horizontal = TRUE, col = "#004B85",
        main = "Duración de 49 brocas: anatomía del boxplot",
        xlab = "No. de huecos antes de romperse")

abline(v = c(valla_inf, valla_sup), col = "#D9534F", lty = 2)
abline(v = c(ext_inf, ext_sup), col = "#B37D00", lty = 3)

legend("topright",
       legend = c("Vallas internas (1.5·RIC)", "Vallas externas (3·RIC)"),
       col = c("#D9534F", "#B37D00"), lty = c(2, 3), bty = "n", cex = 0.8)
```

::: {.callout-note}
## Lo que deberías notar
Fíjate en la distancia entre la línea roja de la derecha (valla interna, 283) y donde realmente termina el bigote (270): ese espacio vacío es normal y confirma el Paso 7. Y observa que el 30, a la izquierda, queda fuera de su valla roja — es el atípico que se pasa por alto si uno solo mira la cola larga.
:::

## 🗂️ Resumen

::: {.card-lab}
- Los cuartiles dividen los datos ordenados en cuatro partes iguales; el RIC mide la dispersión del 50% central, sin verse afectado por valores extremos.
- **El procedimiento completo son 7 pasos:** ordenar → posición del cuartil ($h=(n-1)p+1$) → leer el valor → RIC → vallas → identificar atípicos → ubicar los bigotes.
- La regla estándar de valores atípicos usa $Q_3 + 1.5 \cdot RIC$ y $Q_1 - 1.5 \cdot RIC$ como límites — y hay que aplicarla **a los dos extremos**, no solo al que salta a la vista.
- **Los bigotes no llegan hasta las vallas:** llegan hasta el último dato real que queda dentro de ellas.
- Un boxplot resume 5 números (bigote inferior, Q1, mediana, Q3, bigote superior) y hace visibles la mediana, la dispersión y los atípicos en un solo vistazo — sin necesitar el promedio.
- `boxplot(x, plot = FALSE)$stats` te devuelve esos cinco números para verificar tus cálculos a mano.
:::

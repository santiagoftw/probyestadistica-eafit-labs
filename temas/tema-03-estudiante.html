🌋 ¿Qué tan “fiel” es Old Faithful?

El géiser Old Faithful (Yellowstone) es famoso por ser predecible. Si midieras la duración de 272 erupciones, ¿esperarías una sola forma de campana, o podría haber algo más raro escondido en los datos?

Antes de seguir: dibuja (mentalmente o en papel) la forma que crees que tendría el histograma de duraciones. ¿Una sola montaña? ¿Dos?

🔬 Exploremos: cuando “una fila por valor” deja de funcionar

En la Clase 2 hicimos tablas de frecuencia con una fila por categoría. Prueba hacer lo mismo con estos 20 tiempos (en minutos):

1.75, 3.10, 4.20, 1.95, 4.35, 3.87, 1.83, 4.42, 3.55, 1.60,
4.10, 2.05, 3.92, 1.88, 4.28, 3.63, 2.15, 4.05, 1.72, 3.78

¿Cuántas filas tendría tu tabla si haces una por valor distinto? ¿Sigue resumiendo algo, o casi tienes tantas filas como datos?

🎛️ Simulación: ¿cuántos intervalos usar?

Mueve el número de intervalos del histograma de faithful$eruptions (272 erupciones reales del géiser, dataset incluido en R) y observa qué aparece — y qué desaparece.

Code 
data(faithful)

hist(faithful$eruptions, breaks = 3, col = "#004B85", border = "white",
     main = "breaks = 3", xlab = "Duración (min)", ylab = "Frecuencia")

hist(faithful$eruptions, breaks = 30, col = "#004B85", border = "white",
     main = "breaks = 30", xlab = "Duración (min)", ylab = "Frecuencia")
NoteLo que deberías notar

Con breaks = 3 el histograma parece una sola montaña — pero con más intervalos aparecen dos picos claros. La duración de las erupciones no es “un solo tipo”: hay erupciones cortas y erupciones largas, con pocas intermedias.

📖 Ahora sí, la teoría

Cómo se construye una tabla de frecuencias agrupada

  • Histograma (Rincón, 2017)
  • Regla de Sturges
  • Simetría y sesgo
  • Modalidad

Una gráfica similar a la de barras, pero sin espacios entre las barras — porque una variable continua no tiene “huecos” entre categorías: fluye de un valor a otro. Cada barra representa un intervalo (clase), y su altura es la frecuencia (absoluta, relativa o porcentual) de datos que caen en ese intervalo.

Una guía práctica para elegir cuántos intervalos (\(k\)) usar al agrupar \(n\) observaciones:

\[k = 1 + 3.3 \cdot \log_{10}(n)\]

Con \(k\) ya definido, el ancho de cada clase se calcula como:

\[w = \frac{\text{rango}}{k} = \frac{\text{máximo} - \text{mínimo}}{k}\]

normalmente redondeado hacia arriba a un número conveniente. No es una ley exacta — es un punto de partida razonable. R usa un algoritmo basado en esta misma idea por defecto en hist(), pero permite forzar cualquier valor con el argumento breaks.

  • Simétrica: los datos se distribuyen de forma pareja alrededor del centro (forma de campana).
  • Sesgada a la derecha (asimetría positiva): cola larga hacia valores altos — hay algunos valores mucho más grandes que el resto.
  • Sesgada a la izquierda (asimetría negativa): cola larga hacia valores bajos.
  • Unimodal: un solo pico — la mayoría de los datos se agrupan en torno a un único valor central.
  • Bimodal / multimodal: dos o más picos — puede sugerir que los datos provienen de dos o más grupos o procesos distintos, mezclados en la misma muestra (como en faithful$eruptions).

Las 4 formas típicas, con datos reales

Cada panel de abajo se genera con datos simulados que siguen exactamente el patrón que describe su nombre — no son dibujos, son histogramas reales de R:

Code 
set.seed(42)
par(mfrow = c(2, 2), mar = c(3, 3, 3, 1))

# Simétrica
x1 <- rnorm(2000, mean = 50, sd = 10)
hist(x1, breaks = 25, col = "#004B85", border = "white",
     main = "Simétrica", xlab = "", ylab = "")

# Sesgada a la derecha
x2 <- rgamma(2000, shape = 2, rate = 0.1)
hist(x2, breaks = 25, col = "#FFB903", border = "white",
     main = "Sesgada a la derecha", xlab = "", ylab = "")

# Sesgada a la izquierda
x3 <- 100 - rgamma(2000, shape = 2, rate = 0.1)
hist(x3, breaks = 25, col = "#4B8BC2", border = "white",
     main = "Sesgada a la izquierda", xlab = "", ylab = "")

# Bimodal
x4 <- c(rnorm(1000, 30, 5), rnorm(1000, 70, 5))
hist(x4, breaks = 25, col = "#B37D00", border = "white",
     main = "Bimodal", xlab = "", ylab = "")
NotePrueba tú mismo

Cambia shape o rate en rgamma(), o las medias en el ejemplo bimodal, y vuelve a correr el chunk. ¿Qué tan sesgada puedes hacer una distribución antes de que dejes de reconocerla como “campana deformada”?

Tip💡 Truco de interpretación

Si alguien te presenta un histograma sin decir cuántos breaks usó, no confíes todavía en su forma. Como viste con Old Faithful, muy pocos intervalos pueden esconder por completo una bimodalidad real. La forma “definitiva” de una distribución solo se puede afirmar después de probar con distintos niveles de agrupamiento. Ver más trucos →

🛠️ Cuatro maneras de hacerlo en R

Para una variable continua, la tabla agrupada y el histograma también se pueden construir de cuatro formas. La manual te muestra los 5 pasos del diagrama de arriba uno por uno; hist() los automatiza; tidyverse (cut() + count()) es la más cómoda cuando ya vienes trabajando con dplyr; ggplot2 te da el control fino para informes.

  • Manera 1 · Construcción manual (con cut())
  • Manera 2 · hist() de R base
  • Manera 3 · tidyverse (dplyr)
  • Manera 4 · ggplot2

Replica a mano los 5 pasos: rango → k (Sturges) → ancho de clase → límites → conteo. La función cut() asigna cada dato a su intervalo, y table() cuenta. De aquí en adelante usamos SqFt (área en pies cuadrados) del dataset houses (el mismo de los Temas 0-2):

Code 
houses <- read.csv("../data/house-prices.csv")
x <- houses$SqFt
n <- length(x)

# Paso 1-3: rango, k por Sturges, ancho de clase
rango <- max(x) - min(x)
k <- ceiling(1 + 3.3 * log10(n))
w <- rango / k
c(rango = rango, k = k, ancho = round(w, 3))
 rango      k  ancho 
1140.0    8.0  142.5
Code 
# Paso 4: límites de clase
limites <- seq(min(x), max(x), length.out = k + 1)

# Paso 5: asignar cada dato a su clase y contar
clases <- cut(x, breaks = limites, include.lowest = TRUE)
tabla_agrupada <- data.frame(
  Intervalo       = levels(clases),
  Frec_absoluta   = as.vector(table(clases)),
  Frec_relativa   = round(as.vector(table(clases)) / n, 3),
  Frec_acumulada  = cumsum(as.vector(table(clases)))
)

El “histograma manual” es un barplot() de esa tabla, con las barras pegadas (space = 0):

Code 
barplot(tabla_agrupada$Frec_absoluta, space = 0,
        names.arg = round(limites[-1], 1),
        col = "#004B85", border = "white",
        xlab = "Estatura (cm)", ylab = "Frecuencia",
        main = "Histograma construido manualmente")

Todo lo anterior en una sola línea — R aplica internamente una regla tipo Sturges, o puedes forzar el número de cortes con breaks:

Code 
h <- hist(houses$SqFt, breaks = k,
          col = "#004B85", border = "white",
          xlab = "Estatura (cm)", ylab = "Frecuencia",
          main = "hist() de R base")

Un detalle útil: hist() devuelve un objeto con toda la tabla agrupada calculada — puedes inspeccionarlo:

Code 
h$breaks   # límites de clase que usó
[1] 1400 1600 1800 2000 2200 2400 2600
Code 
h$counts   # frecuencias absolutas por clase
[1]  4 19 44 41 13  7

La misma idea de cut() + table(), pero encadenada con mutate() y count() — el resultado es directamente un data frame, sin pasos de conversión aparte:

Code 
library(tidyverse)

tabla_tidy <- tibble(estatura = houses$SqFt) |>
  mutate(clase = cut(estatura, breaks = limites, include.lowest = TRUE)) |>
  count(clase, name = "Frec_absoluta") |>
  mutate(
    Frec_relativa  = round(Frec_absoluta / sum(Frec_absoluta), 3),
    Frec_acumulada = cumsum(Frec_absoluta)
  )

       title = "Histograma construido con tidyverse") +

geom_histogram() con control del número de barras (bins) o del ancho de clase (binwidth) — más una línea de la media, como en el laboratorio del curso:

Code 
library(ggplot2)

ggplot(houses, aes(x = SqFt)) +
  geom_histogram(bins = k, fill = "#004B85", color = "white") +
  geom_vline(aes(xintercept = mean(SqFt)),
             color = "#FFB903", linetype = "dashed", linewidth = 1) +
  labs(x = "Estatura (cm)", y = "Frecuencia",
       title = "geom_histogram() con la media marcada") +

Tip¿Cuál usar?
  • Manual (cut() + table()) cuando el ejercicio pide la tabla de distribución de frecuencias explícita, o cuando los límites de clase deben ser valores “redondos” con sentido práctico (por ejemplo, de 10 en 10) en vez de los que da la fórmula.
  • hist() para explorar rápido y para acceder a la tabla interna con h$breaks y h$counts.
  • tidyverse (cut() + count()) cuando quieres la tabla agrupada como data frame para seguir filtrando, uniendo con otras tablas, o graficando con ggplot2 a partir de ahí.
  • ggplot2 para informes, y cuando quieras superponer capas (media, densidad, comparación por grupos con color = Grupo).

Otro ejemplo: la tabla agrupada completa, paso a paso, con límites “redondos”

El ejemplo anterior se detuvo en el histograma. Aquí completamos los 5 pasos hasta la tabla de frecuencias agrupada, redondeando la amplitud de clase a un valor práctico (en vez de usar la amplitud exacta que da la fórmula):

Code 
precios <- houses$Price

# Paso 1-3: rango, k (Sturges) y amplitud de clase
rango  <- max(precios) - min(precios)
k      <- ceiling(1 + 3.3 * log10(length(precios)))
amplitud <- rango / k
c(rango = round(rango,1), k = k, amplitud = round(amplitud, 2))
   rango        k amplitud 
142100.0      8.0  17762.5
Code 
# Paso 4-5: límites e intervalos (amplitud redondeada a un valor práctico), y conteo
amplitud_practica <- ceiling(amplitud / 1000) * 1000
limites <- seq(floor(min(precios) / 1000) * 1000, by = amplitud_practica, length.out = k + 1)
clases  <- cut(precios, breaks = limites, right = FALSE, include.lowest = TRUE)

tabla_precios <- data.frame(
  Intervalo          = levels(clases),
  Frec_absoluta      = as.vector(table(clases)),
  Frec_acumulada     = cumsum(as.vector(table(clases))),
  Frec_relativa      = round(as.vector(table(clases)) / length(precios), 3),
  Frec_rel_acumulada = round(cumsum(as.vector(table(clases))) / length(precios), 3)
)

NoteLo que deberías notar

Aquí se redondeó la amplitud hacia arriba, al millar más cercano (de $17,762.5 a $18,000) antes de construir los límites, en vez de usar seq(..., length.out = k+1) con la amplitud exacta como en la sección de “Cuatro maneras” (con SqFt). Es la diferencia que menciona la teoría de este tema: cuando quieres límites “redondos” y fáciles de leer en un informe (aquí, precios en miles cerrados en vez de decimales), redondeas la amplitud antes de construir los cortes — el número de intervalos (\(k\)) es el mismo de cualquier forma, pero los límites concretos cambian.

Ejercicio 2 — Verdadero o falso

🗂️ Resumen

  • Una variable continua se agrupa en intervalos antes de tabular — “una fila por valor” no resume nada.
  • La regla de Sturges (\(k = 1 + 3.3 \log_{10} n\)) da un punto de partida razonable para el número de clases, no una respuesta única.
  • Un histograma puede revelar formas (sesgo, bimodalidad) que un solo número como el promedio no muestra — como en el caso real de Old Faithful.

## Histograma (Rincón, 2017)
Una gráfica similar a la de barras, pero **sin espacios entre las barras** — porque una variable continua no tiene "huecos" entre categorías: fluye de un valor a otro. Cada barra representa un intervalo (clase), y su altura es la frecuencia (absoluta, relativa o porcentual) de datos que caen en ese intervalo.

## Regla de Sturges
Una guía práctica para elegir cuántos intervalos ($k$) usar al agrupar $n$ observaciones:

$$k = 1 + 3.3 \cdot \log_{10}(n)$$

Con $k$ ya definido, el **ancho de cada clase** se calcula como:

$$w = \frac{\text{rango}}{k} = \frac{\text{máximo} - \text{mínimo}}{k}$$

normalmente redondeado hacia arriba a un número conveniente. No es una ley exacta — es un punto de partida razonable. R usa un algoritmo basado en esta misma idea por defecto en `hist()`, pero permite forzar cualquier valor con el argumento `breaks`.

## Simetría y sesgo
- **Simétrica:** los datos se distribuyen de forma pareja alrededor del centro (forma de campana).
- **Sesgada a la derecha (asimetría positiva):** cola larga hacia valores altos — hay algunos valores mucho más grandes que el resto.
- **Sesgada a la izquierda (asimetría negativa):** cola larga hacia valores bajos.

## Modalidad
- **Unimodal:** un solo pico — la mayoría de los datos se agrupan en torno a un único valor central.
- **Bimodal / multimodal:** dos o más picos — puede sugerir que los datos provienen de dos o más grupos o procesos distintos, mezclados en la misma muestra (como en `faithful$eruptions`).

:::

### Las 4 formas típicas, con datos reales

Cada panel de abajo se genera con datos simulados que siguen exactamente el patrón que describe su nombre — no son dibujos, son histogramas reales de R:

```{r}
#| label: fig-cuatro-formas
#| fig-cap: "Las cuatro formas típicas de una distribución, generadas con datos reales"
set.seed(42)
par(mfrow = c(2, 2), mar = c(3, 3, 3, 1))

# Simétrica
x1 <- rnorm(2000, mean = 50, sd = 10)
hist(x1, breaks = 25, col = "#004B85", border = "white",
     main = "Simétrica", xlab = "", ylab = "")

# Sesgada a la derecha
x2 <- rgamma(2000, shape = 2, rate = 0.1)
hist(x2, breaks = 25, col = "#FFB903", border = "white",
     main = "Sesgada a la derecha", xlab = "", ylab = "")

# Sesgada a la izquierda
x3 <- 100 - rgamma(2000, shape = 2, rate = 0.1)
hist(x3, breaks = 25, col = "#4B8BC2", border = "white",
     main = "Sesgada a la izquierda", xlab = "", ylab = "")

# Bimodal
x4 <- c(rnorm(1000, 30, 5), rnorm(1000, 70, 5))
hist(x4, breaks = 25, col = "#B37D00", border = "white",
     main = "Bimodal", xlab = "", ylab = "")
```

## 💡 Truco de interpretación
Si alguien te presenta un histograma sin decir cuántos `breaks` usó, no confíes todavía en su forma. Como viste con Old Faithful, muy pocos intervalos pueden esconder por completo una bimodalidad real. La forma "definitiva" de una distribución solo se puede afirmar después de probar con distintos niveles de agrupamiento. [Ver más trucos →](../recursos.qmd)
:::

## 🛠️ Cuatro maneras de hacerlo en R

Para una variable continua, la tabla agrupada y el histograma también se pueden construir de cuatro formas. La manual te muestra los 5 pasos del diagrama de arriba uno por uno; `hist()` los automatiza; `tidyverse` (`cut()` + `count()`) es la más cómoda cuando ya vienes trabajando con `dplyr`; `ggplot2` te da el control fino para informes.

::: {.panel-tabset}

## Manera 1 · Construcción manual (con `cut()`)

Replica a mano los 5 pasos: rango → k (Sturges) → ancho de clase → límites → conteo. La función `cut()` asigna cada dato a su intervalo, y `table()` cuenta. De aquí en adelante usamos `SqFt` (área en pies cuadrados) del dataset `houses` (el mismo de los Temas 0-2):

```{r}
houses <- read.csv("../data/house-prices.csv")
x <- houses$SqFt
n <- length(x)

# Paso 1-3: rango, k por Sturges, ancho de clase
rango <- max(x) - min(x)
k <- ceiling(1 + 3.3 * log10(n))
w <- rango / k
c(rango = rango, k = k, ancho = round(w, 3))

# Paso 4: límites de clase
limites <- seq(min(x), max(x), length.out = k + 1)

# Paso 5: asignar cada dato a su clase y contar
clases <- cut(x, breaks = limites, include.lowest = TRUE)
tabla_agrupada <- data.frame(
  Intervalo       = levels(clases),
  Frec_absoluta   = as.vector(table(clases)),
  Frec_relativa   = round(as.vector(table(clases)) / n, 3),
  Frec_acumulada  = cumsum(as.vector(table(clases)))
)
tabla_agrupada
```

El "histograma manual" es un `barplot()` de esa tabla, con las barras pegadas (`space = 0`):

```{r}
barplot(tabla_agrupada$Frec_absoluta, space = 0,
        names.arg = round(limites[-1], 1),
        col = "#004B85", border = "white",
        xlab = "Estatura (cm)", ylab = "Frecuencia",
        main = "Histograma construido manualmente")
```

## Manera 2 · `hist()` de R base

Todo lo anterior en una sola línea — R aplica internamente una regla tipo Sturges, o puedes forzar el número de cortes con `breaks`:

```{r}
h <- hist(houses$SqFt, breaks = k,
          col = "#004B85", border = "white",
          xlab = "Estatura (cm)", ylab = "Frecuencia",
          main = "hist() de R base")
```

Un detalle útil: `hist()` **devuelve un objeto** con toda la tabla agrupada calculada — puedes inspeccionarlo:

```{r}
h$breaks   # límites de clase que usó
h$counts   # frecuencias absolutas por clase
```

## Manera 3 · `tidyverse` (`dplyr`)

La misma idea de `cut()` + `table()`, pero encadenada con `mutate()` y `count()` — el resultado es directamente un data frame, sin pasos de conversión aparte:

```{r}
#| message: false
library(tidyverse)

tabla_tidy <- tibble(estatura = houses$SqFt) |>
  mutate(clase = cut(estatura, breaks = limites, include.lowest = TRUE)) |>
  count(clase, name = "Frec_absoluta") |>
  mutate(
    Frec_relativa  = round(Frec_absoluta / sum(Frec_absoluta), 3),
    Frec_acumulada = cumsum(Frec_absoluta)
  )
tabla_tidy
```

Y el histograma correspondiente, graficando directamente esa tabla ya agrupada con `geom_col()` (la versión de `geom_bar()` para cuando las alturas ya están calculadas):

```{r}
ggplot(tabla_tidy, aes(x = clase, y = Frec_absoluta)) +
  geom_col(fill = "#004B85", color = "white", width = 1) +
  labs(x = "Estatura (cm)", y = "Frecuencia",
       title = "Histograma construido con tidyverse") +
  theme_minimal() +
  theme(axis.text.x = element_text(angle = 45, hjust = 1))
```

## Manera 4 · ggplot2

`geom_histogram()` con control del número de barras (`bins`) o del ancho de clase (`binwidth`) — más una línea de la media, como en el laboratorio del curso:

```{r}
#| message: false
library(ggplot2)

ggplot(houses, aes(x = SqFt)) +
  geom_histogram(bins = k, fill = "#004B85", color = "white") +
  geom_vline(aes(xintercept = mean(SqFt)),
             color = "#FFB903", linetype = "dashed", linewidth = 1) +
  labs(x = "Estatura (cm)", y = "Frecuencia",
       title = "geom_histogram() con la media marcada") +
  theme_minimal()
```

:::

::: {.callout-tip}
## ¿Cuál usar?
- **Manual (`cut()` + `table()`)** cuando el ejercicio pide *la tabla de distribución de frecuencias* explícita, o cuando los límites de clase deben ser valores "redondos" con sentido práctico (por ejemplo, de 10 en 10) en vez de los que da la fórmula.
- **`hist()`** para explorar rápido y para acceder a la tabla interna con `h$breaks` y `h$counts`.
- **`tidyverse` (`cut()` + `count()`)** cuando quieres la tabla agrupada como data frame para seguir filtrando, uniendo con otras tablas, o graficando con `ggplot2` a partir de ahí.
- **ggplot2** para informes, y cuando quieras superponer capas (media, densidad, comparación por grupos con `color = Grupo`).
:::

### Otro ejemplo: la tabla agrupada completa, paso a paso, con límites "redondos"

El ejemplo anterior se detuvo en el histograma. Aquí completamos los 5 pasos hasta la tabla de frecuencias agrupada, redondeando la amplitud de clase a un valor práctico (en vez de usar la amplitud exacta que da la fórmula):

```{r}
precios <- houses$Price

# Paso 1-3: rango, k (Sturges) y amplitud de clase
rango  <- max(precios) - min(precios)
k      <- ceiling(1 + 3.3 * log10(length(precios)))
amplitud <- rango / k
c(rango = round(rango,1), k = k, amplitud = round(amplitud, 2))

# Paso 4-5: límites e intervalos (amplitud redondeada a un valor práctico), y conteo
amplitud_practica <- ceiling(amplitud / 1000) * 1000
limites <- seq(floor(min(precios) / 1000) * 1000, by = amplitud_practica, length.out = k + 1)
clases  <- cut(precios, breaks = limites, right = FALSE, include.lowest = TRUE)

tabla_precios <- data.frame(
  Intervalo          = levels(clases),
  Frec_absoluta      = as.vector(table(clases)),
  Frec_acumulada     = cumsum(as.vector(table(clases))),
  Frec_relativa      = round(as.vector(table(clases)) / length(precios), 3),
  Frec_rel_acumulada = round(cumsum(as.vector(table(clases))) / length(precios), 3)
)
tabla_precios
```

::: {.callout-note}
## Lo que deberías notar
Aquí se redondeó la amplitud **hacia arriba, al millar más cercano** (de \$17,762.5 a \$18,000) antes de construir los límites, en vez de usar `seq(..., length.out = k+1)` con la amplitud exacta como en la sección de "Cuatro maneras" (con `SqFt`). Es la diferencia que menciona la teoría de este tema: cuando quieres límites "redondos" y fáciles de leer en un informe (aquí, precios en miles cerrados en vez de decimales), redondeas la amplitud antes de construir los cortes — el número de intervalos ($k$) es el mismo de cualquier forma, pero los límites concretos cambian.
:::

## 🗂️ Resumen

::: {.card-lab}
- Una variable continua se agrupa en intervalos antes de tabular — "una fila por valor" no resume nada.
- La regla de Sturges ($k = 1 + 3.3 \log_{10} n$) da un punto de partida razonable para el número de clases, no una respuesta única.
- Un histograma puede revelar formas (sesgo, bimodalidad) que un solo número como el promedio no muestra — como en el caso real de Old Faithful.
:::

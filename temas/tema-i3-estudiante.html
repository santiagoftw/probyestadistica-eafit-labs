📏 Un solo número nunca dice qué tan seguro estás

Si alguien te dice “la resistencia promedio de estas toallas de papel es 9322.7 g”, ¿qué tan cerca de la realidad crees que está ese número? Un valor puntual, por sí solo, no dice nada sobre su propia precisión. Un intervalo de confianza responde la pregunta que el punto no puede: no solo “¿cuál es mi mejor estimación?”, sino “¿en qué rango puedo confiar, y con qué nivel de seguridad?”.

NoteFuente de este tema

Basado en Walpole, R., Myers, R., Myers, S., y Ye, K., Probabilidad y Estadística para Ingeniería y Ciencias, Capítulo 7 (Secciones 7.1-7.3). Todos los resultados numéricos —incluidos dos conjuntos de datos reales completos— fueron verificados de forma independiente.

Si repitieras un experimento 1000 veces y calcularas un intervalo de confianza del 95% cada vez, ¿cuántos de esos 1000 intervalos esperarías que sí contengan el verdadero valor del parámetro? ¿Y cuántos no?

🔬 Exploremos: qué tan seguido “falla” un intervalo de confianza

Code 
set.seed(1)
mu_real <- 100; sigma <- 15; n <- 30

# Simular 1000 muestras, calcular el IC de 95% de cada una,
# y contar en cuántas SÍ quedó atrapado el verdadero mu=100
contiene_mu <- replicate(1000, {
  muestra <- rnorm(n, mu_real, sigma)
  xbar <- mean(muestra)
  margen <- 1.96 * sigma / sqrt(n)
  (xbar - margen <= mu_real) & (mu_real <= xbar + margen)
})

mean(contiene_mu)   # proporción de intervalos que sí atraparon a mu
[1] 0.959

Aproximadamente 95% de los 1000 intervalos simulados contienen el verdadero \(\mu=100\) — el otro ~5% no lo logra, simplemente por la variabilidad del muestreo. Esta simulación es literalmente lo que significa “95% de confianza”: no que este intervalo particular tenga 95% de probabilidad de contener a \(\mu\) (una vez calculado, o lo contiene o no —ya no hay aleatoriedad—), sino que el procedimiento que lo generó acierta 95% de las veces a la larga.

📖 Ahora sí, la teoría

  • 1. Qué es (y qué NO es) un intervalo de confianza
  • 2. \(\mu\) con \(\sigma\) conocida
  • 3. \(\mu\) con \(\sigma\) desconocida, muestra grande
  • 4. \(\mu\) con \(\sigma\) desconocida, muestra pequeña (t)

Un intervalo de confianza de \(100(1-\alpha)\%\) para un parámetro es un rango de valores, calculado a partir de la muestra, tal que si el procedimiento se repitiera muchas veces, aproximadamente \(100(1-\alpha)\%\) de los intervalos resultantes contendrían el verdadero valor del parámetro.

ImportantEl error de interpretación más común

Una vez calculado un intervalo específico, como \((79.3,\,80.7)\), es incorrecto decir “hay 95% de probabilidad de que \(\mu\) esté en \((79.3, 80.7)\)”. \(\mu\) es una constante fija (desconocida, pero fija); el intervalo ya está calculado y ya no es aleatorio. Lo correcto es decir que se tiene 95% de confianza en el procedimiento que produjo ese intervalo — la aleatoriedad estaba en la muestra, no en el parámetro.

\[\bar{x} \pm z_{\alpha/2}\cdot\frac{\sigma}{\sqrt{n}}\]

El caso más simple (aunque menos realista: rara vez se conoce \(\sigma\) sin conocer también \(\mu\)). Sirve como base para todo lo que sigue.

Cuando \(\sigma\) no se conoce pero \(n\) es grande (regla práctica: \(n>40\)), el Teorema Central del Límite permite sustituir \(\sigma\) por \(s\) sin mayor pérdida de precisión:

\[\bar{x} \pm z_{\alpha/2}\cdot\frac{s}{\sqrt{n}}\]

Para una proporción poblacional \(p\) (con \(\hat{p}=x/n\)), la versión simple análoga es:

\[\hat{p} \pm z_{\alpha/2}\sqrt{\frac{\hat{p}(1-\hat{p})}{n}}\]

(existe una versión ajustada, más precisa para \(n\) chico o \(\hat p\) cerca de 0 o 1 — la misma idea del método de Wilson que ya usaste en el Ítem 41 del Laboratorio de Inferencia).

Cuando \(n\) es pequeña, ya no se puede invocar el TLC. Si la población de origen es aproximadamente normal, el estadístico correcto usa la distribución t con \(n-1\) grados de libertad en vez de la normal:

\[\bar{x} \pm t_{\alpha/2,\,n-1}\cdot\frac{s}{\sqrt{n}}\]

Misma estructura que los dos casos anteriores — solo cambia de dónde sale el valor crítico. La curva \(t\) es más dispersa que la normal estándar (más “pesada” en las colas), y se acerca a la normal cuando \(n\to\infty\) — por eso la regla práctica de \(n>40\) del caso anterior funciona: ahí \(t\) y \(z\) ya casi coinciden.

🧪 Segundo ejemplo: muestra pequeña con t (n = 16)

Enunciado: se midió el módulo de elasticidad (MPa) de 16 especímenes de madera de pino escocés. Suponiendo una población aproximadamente normal, calcule un IC de 95%.

n <- length(datos)
xbar <- mean(datos)

t_critico <- qt(0.975, df = n - 1)
margen <- t_critico * s / sqrt(n)

c(n = n, xbar = xbar, s = s, t_critico = t_critico, margen = margen)

Code

Con solo \(n=16\) y una desviación estándar considerable (\(s\approx2056\)), el intervalo resultante es bastante amplio: \((13437,\,15628)\) — un rango de más de 2000 MPa. Compáralo con el ejemplo anterior: menos datos y más variabilidad se traducen directamente en un intervalo menos preciso, a pesar de usar el mismo nivel de confianza (95%).

Tip💡 Truco de interpretación

El ancho del intervalo depende de tres cosas: el nivel de confianza (más confianza → más ancho), la variabilidad de los datos (\(s\) más grande → más ancho), y el tamaño de muestra (\(n\) más grande → más angosto, porque el error estándar \(s/\sqrt{n}\) encoge). De las tres, el tamaño de muestra es la única que el investigador puede controlar de antemano. Ver más trucos →

🔗 Bonus: intervalo de confianza para una proporción

Enunciado: en 48 ensayos de ignición de cierto sustrato, 16 resultaron en ignición. Calcule un IC de 95% para la proporción real \(p\).

Code 
x <- 16; n <- 48
p_hat <- x / n

# Fórmula simple (7.11)
margen_simple <- qnorm(0.975) * sqrt(p_hat * (1 - p_hat) / n)
c(p_hat = p_hat, IC_simple = c(p_hat - margen_simple, p_hat + margen_simple))
     p_hat IC_simple1 IC_simple2 
 0.3333333  0.1999747  0.4666920
Code 
# prop.test() usa una versión ajustada (más precisa), como la del Ítem 41
prop.test(x, n, correct = FALSE)$conf.int
[1] 0.2167678 0.4745989
attr(,"conf.level")
[1] 0.95

La fórmula simple da \((0.200,\,0.467)\); la versión ajustada de prop.test() da \((0.217,\,0.474)\) — parecidos, pero no idénticos. Con \(n\) moderado y \(\hat p\) no tan cerca de 0.5, esta diferencia es el precio de la fórmula simple: funciona razonablemente bien, pero la ajustada es más confiable, como ya viste en el Ítem 41.

🧑‍🔬 Laboratorio

  1. Muestra pequeña, tú resuelves. El contenido de grasa (%) de una muestra de 10 hot dogs: 25.2, 21.3, 22.8, 17.0, 29.8, 21.0, 25.5, 16.0, 20.9, 19.5. Suponiendo una población normal, calcula un IC de 95% para el contenido de grasa promedio real.

  2. El efecto del nivel de confianza. Usando los mismos 48 datos de tensión disruptiva del primer ejemplo, calcula el IC con 90%, 95% y 99% de confianza. ¿Cómo cambia el ancho del intervalo? ¿Tiene sentido esa dirección de cambio?

  3. Tamaño de muestra necesario. Un investigador quiere estimar la tensión disruptiva promedio con un IC de 95% que tenga una extensión total de a lo sumo 2 kV (es decir, margen de error \(\le1\)). Si estima que \(\sigma\approx7.5\), ¿qué tamaño de muestra \(n\) necesita? (Pista: despeja \(n\) de \(z_{\alpha/2}\cdot\sigma/\sqrt{n}\le1\)).

✅ Ejercicios autocorregibles

Ejercicio 1 — Completa el código

# IC de 95% para mu, sigma=12 conocida, n=50, xbar=200
xbar <- 200; sigma <- 12; n <- 50
margen <- qnorm(0.975) * sigma / sqrt(___)
c(inferior = xbar - margen, superior = xbar + margen)
Ver respuesta n — el error estándar siempre se calcula como \(\sigma/\sqrt{n}\) (o \(s/\sqrt{n}\)), dividiendo entre la raíz del tamaño de muestra.

Ejercicio 2 — Completa el código

# IC t de 90% para mu, n=12 (muestra pequena), xbar=45, s=6
xbar <- 45; s <- 6; n <- 12
t_critico <- qt(0.95, df = ___)
margen <- t_critico * s / sqrt(n)
c(inferior = xbar - margen, superior = xbar + margen)
Ver respuesta n - 1 — los grados de libertad de la distribución t para un IC de una sola muestra siempre son \(n-1\).

Ejercicio 3 — Verdadero o falso

1. Un IC de 95% significa que hay 95% de probabilidad de que el parámetro esté en ese intervalo específico.
2. Un tamaño de muestra más grande produce, en general, un intervalo más angosto.
3. Cuando sigma es desconocida y n es pequeña, se debe usar la distribución t en vez de la normal.
4. Un mayor nivel de confianza (por ejemplo 99% en vez de 95%) siempre produce un intervalo más angosto.
5. La distribución t se acerca a la distribución normal estándar cuando los grados de libertad crecen.

🗂️ Resumen

  • Un IC de \(100(1-\alpha)\%\) es un procedimiento que, repetido muchas veces, produce intervalos que contienen al verdadero parámetro \(100(1-\alpha)\%\) de las veces — no una afirmación de probabilidad sobre un intervalo particular ya calculado.
  • Misma estructura en los tres casos: estimación \(\pm\) (valor crítico) \(\times\) (error estándar) — solo cambia de dónde sale el valor crítico (\(z\) o \(t\)) y qué se usa como error estándar (\(\sigma/\sqrt n\) o \(s/\sqrt n\)).
  • \(\sigma\) conocida → \(z\). \(\sigma\) desconocida y \(n\) grande (\(n>40\)) → \(z\) con \(s\) en vez de \(\sigma\). \(\sigma\) desconocida y \(n\) chica (población normal) → \(t\) con \(n-1\) grados de libertad.
  • El ancho del intervalo depende del nivel de confianza, la variabilidad de los datos, y el tamaño de muestra — de los tres, solo \(n\) está bajo control directo del investigador antes de recolectar datos.
NoteCon esto se completa el núcleo de inferencia con una muestra

## 🔗 Bonus: intervalo de confianza para una proporción

**Enunciado:** en 48 ensayos de ignición de cierto sustrato, 16 resultaron en ignición. Calcule un IC de 95% para la proporción real $p$.

```{r}
p_hat <- x / n

# Fórmula simple (7.11)
margen_simple <- qnorm(0.975) * sqrt(p_hat * (1 - p_hat) / n)
c(p_hat = p_hat, IC_simple = c(p_hat - margen_simple, p_hat + margen_simple))
```

```{r}
# prop.test() usa una versión ajustada (más precisa), como la del Ítem 41
prop.test(x, n, correct = FALSE)$conf.int
```

::: {.ficha-resultado}
La fórmula simple da $(0.200,\,0.467)$; la versión ajustada de `prop.test()` da $(0.217,\,0.474)$ — parecidos, pero no idénticos. Con $n$ moderado y $\hat p$ no tan cerca de 0.5, esta diferencia es el precio de la fórmula simple: funciona razonablemente bien, pero la ajustada es más confiable, como ya viste en el Ítem 41.
:::

## 🗂️ Resumen

::: {.card-lab}
- Un IC de $100(1-\alpha)\%$ es un procedimiento que, repetido muchas veces, produce intervalos que contienen al verdadero parámetro $100(1-\alpha)\%$ de las veces — no una afirmación de probabilidad sobre un intervalo particular ya calculado.
- Misma estructura en los tres casos: estimación $\pm$ (valor crítico) $\times$ (error estándar) — solo cambia de dónde sale el valor crítico ($z$ o $t$) y qué se usa como error estándar ($\sigma/\sqrt n$ o $s/\sqrt n$).
- $\sigma$ conocida → $z$. $\sigma$ desconocida y $n$ grande ($n>40$) → $z$ con $s$ en vez de $\sigma$. $\sigma$ desconocida y $n$ chica (población normal) → $t$ con $n-1$ grados de libertad.
- El ancho del intervalo depende del nivel de confianza, la variabilidad de los datos, y el tamaño de muestra — de los tres, solo $n$ está bajo control directo del investigador antes de recolectar datos.
:::

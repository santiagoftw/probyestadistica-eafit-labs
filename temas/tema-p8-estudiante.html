Tema P8 · Distribución de probabilidad multivariada

  • Show All Code
  • Hide All Code
  • View Source

🪙 Tres monedas, dos variables, una pregunta escondida

Lanzas 3 monedas. \(Y_1\) = número de caras. \(Y_2\) = tu ganancia en una apuesta: si la primera cara sale en el primer tiro, ganas $1; en el segundo, $2; en el tercero, $3; si no sale ninguna cara, pierdes $1. ¿Estas dos variables están relacionadas entre sí, o son independientes?

Antes de calcular: \(Y_2\) depende de cuándo sale la primera cara, y \(Y_1\) del número total de caras. ¿Tu intuición dice que son independientes o no?

🔬 Exploremos: construyendo la tabla conjunta

La forma más segura de construir la tabla conjunta no es “adivinar” una fórmula, sino enumerar los 8 resultados posibles de los 3 lanzamientos y contar directamente:

Code 
# Los 8 resultados igualmente probables de lanzar 3 monedas
monedas <- expand.grid(t1 = c("C", "S"), t2 = c("C", "S"), t3 = c("C", "S"))

# Y1: número total de caras
monedas$Y1 <- rowSums(monedas[, 1:3] == "C")

# Y2: en qué tiro salió la PRIMERA cara (o -1 si no salió ninguna)
primera_cara <- function(fila) {
  pos <- which(fila == "C")
  if (length(pos) == 0) return(-1)
  min(pos)
}
monedas$Y2 <- apply(monedas[, 1:3], 1, primera_cara)

# Tabla conjunta: cuenta cada combinación (Y1,Y2) y divide por los 8 casos
prob_matrix <- table(monedas$Y1, monedas$Y2) / nrow(monedas)
prob_matrix
   
       -1     1     2     3
  0 0.125 0.000 0.000 0.000
  1 0.000 0.125 0.125 0.125
  2 0.000 0.250 0.125 0.000
  3 0.000 0.125 0.000 0.000

Mira la fila Y1=2: la combinación (Y1=2, Y2=1) tiene probabilidad 2/8, el doble que las demás celdas no vacías. ¿Por qué? (pista: hay dos maneras distintas de sacar exactamente 2 caras con la primera cara en el primer tiro: CCS y CSC).

ImportantCorrección de rigor

Una versión anterior de este tema seguía la solución oficial del Laboratorio 3, que calcula la tabla conjunta con una función que solo cubre la diagonal (\(Y_1=1\Rightarrow Y_2=1\), \(Y_1=2\Rightarrow Y_2=2\), etc.), asignando probabilidad 0 a combinaciones que sí son posibles — por ejemplo, CCS y CSC dan \(Y_1=2\) pero \(Y_2=1\) (la primera cara salió en el primer tiro), no \(Y_2=2\). Aquí se corrigió enumerando los 8 resultados directamente en vez de escribir una fórmula a mano — la lección general es que cuando el espacio muestral es pequeño y enumerable, contar es más confiable que “adivinar” una expresión cerrada.

📖 Ahora sí, la teoría

  • Distribución conjunta
  • Distribuciones marginales
  • Distribución condicional
  • Independencia de variables aleatorias

Para dos variables aleatorias discretas \(Y_1, Y_2\), la función de probabilidad conjunta da \(P(Y_1=y_1, Y_2=y_2)\) para cada combinación posible — toda la información sobre cómo se comportan juntas.

Se obtienen “sumando hacia afuera” la variable que no interesa: \[P(Y_1=y_1) = \sum_{y_2} P(Y_1=y_1, Y_2=y_2)\] En R, esto es exactamente rowSums() o colSums() sobre la matriz conjunta.

\[P(Y_1=y_1 | Y_2=y_2) = \frac{P(Y_1=y_1, Y_2=y_2)}{P(Y_2=y_2)}\] La misma idea del Tema P2, ahora aplicada a variables aleatorias en vez de eventos sueltos.

\(Y_1\) y \(Y_2\) son independientes si \(P(Y_1=y_1, Y_2=y_2) = P(Y_1=y_1)\cdot P(Y_2=y_2)\) para toda combinación de valores — no basta con que se cumpla en una sola celda de la tabla.

🧪 Ejemplo con datos reales: marginales, condicional e independencia

Code 
# Marginal de Y2 (columnas están rotuladas -1, 1, 2, 3)
marginal_Y2 <- colSums(prob_matrix)
marginal_Y2
   -1     1     2     3 
0.125 0.500 0.250 0.125
Code 
# Marginal de Y1 (filas están rotuladas 0, 1, 2, 3)
marginal_Y1 <- rowSums(prob_matrix)
marginal_Y1
    0     1     2     3 
0.125 0.375 0.375 0.125
Code 
# Condicional: P(Y1=3 | Y2=1)
p_Y1_3_Y2_1 <- prob_matrix["3", "1"]
p_Y2_1 <- marginal_Y2["1"]
p_Y1_3_dado_Y2_1 <- p_Y1_3_Y2_1 / p_Y2_1
p_Y1_3_dado_Y2_1
   1 
0.25
Code 
# Verificación de independencia: comparar la matriz conjunta contra el producto de marginales
independencia_teorica <- outer(marginal_Y1, marginal_Y2)
round(prob_matrix, 3)
   
       -1     1     2     3
  0 0.125 0.000 0.000 0.000
  1 0.000 0.125 0.125 0.125
  2 0.000 0.250 0.125 0.000
  3 0.000 0.125 0.000 0.000
Code 
round(independencia_teorica, 3)
     -1     1     2     3
0 0.016 0.062 0.031 0.016
1 0.047 0.188 0.094 0.047
2 0.047 0.188 0.094 0.047
3 0.016 0.062 0.031 0.016

Fíjate en la celda (Y1=2, Y2=1): en la tabla conjunta real vale \(2/8=0.25\), pero el producto de marginales da \(P(Y_1=2)\cdot P(Y_2=1) = 0.375 \times 0.5 = 0.1875\) — no coinciden.

ImportantResultado del ejemplo

Las dos matrices de arriba no son iguales — la matriz conjunta real tiene ceros donde el producto de marginales no los tiene. Esto confirma que \(Y_1\) y \(Y_2\) no son independientes: saber en qué tiro salió la primera cara determina información parcial sobre el número total de caras, y viceversa.

De 9 ejecutivos: 4 casados, 3 solteros, 2 divorciados. Se seleccionan 3 al azar. \(Y_1\) = número de casados seleccionados, \(Y_2\) = número de solteros seleccionados.

  1. Construye la función de probabilidad conjunta usando combinaciones (choose()), siguiendo la lógica de una distribución hipergeométrica multivariada.
  2. Obtén la distribución marginal de \(Y_1\).
  3. Si \(Y_3 = 3 - Y_1 - Y_2\) es el número de divorciados seleccionados, calcula \(P(Y_3=1 | Y_2=1)\).

🗂️ Resumen

  • La distribución conjunta contiene toda la información sobre cómo se relacionan dos variables aleatorias.
  • Las marginales se obtienen sumando la tabla conjunta en una dirección; las condicionales dividen una celda entre su marginal correspondiente.
  • La independencia de variables aleatorias exige que la igualdad \(P(Y_1,Y_2)=P(Y_1)P(Y_2)\) se cumpla en todas las combinaciones, no solo en algunas.

## 📖 Ahora sí, la teoría

::: {.panel-tabset}

## Distribución conjunta
Para dos variables aleatorias discretas $Y_1, Y_2$, la función de probabilidad conjunta da $P(Y_1=y_1, Y_2=y_2)$ para cada combinación posible — toda la información sobre cómo se comportan **juntas**.

## Distribuciones marginales
Se obtienen "sumando hacia afuera" la variable que no interesa:
$$P(Y_1=y_1) = \sum_{y_2} P(Y_1=y_1, Y_2=y_2)$$
En R, esto es exactamente `rowSums()` o `colSums()` sobre la matriz conjunta.

## Distribución condicional
$$P(Y_1=y_1 | Y_2=y_2) = \frac{P(Y_1=y_1, Y_2=y_2)}{P(Y_2=y_2)}$$
La misma idea del Tema P2, ahora aplicada a variables aleatorias en vez de eventos sueltos.

## Independencia de variables aleatorias
$Y_1$ y $Y_2$ son independientes si $P(Y_1=y_1, Y_2=y_2) = P(Y_1=y_1)\cdot P(Y_2=y_2)$ para **toda** combinación de valores — no basta con que se cumpla en una sola celda de la tabla.

:::

## 🧪 Ejemplo con datos reales: marginales, condicional e independencia

```{r}
# Marginal de Y2 (columnas están rotuladas -1, 1, 2, 3)
marginal_Y2 <- colSums(prob_matrix)
marginal_Y2

# Marginal de Y1 (filas están rotuladas 0, 1, 2, 3)
marginal_Y1 <- rowSums(prob_matrix)
marginal_Y1
```

```{r}
# Condicional: P(Y1=3 | Y2=1)
p_Y1_3_Y2_1 <- prob_matrix["3", "1"]
p_Y2_1 <- marginal_Y2["1"]
p_Y1_3_dado_Y2_1 <- p_Y1_3_Y2_1 / p_Y2_1
p_Y1_3_dado_Y2_1
```

```{r}
# Verificación de independencia: comparar la matriz conjunta contra el producto de marginales
independencia_teorica <- outer(marginal_Y1, marginal_Y2)
round(prob_matrix, 3)
round(independencia_teorica, 3)
```

Fíjate en la celda `(Y1=2, Y2=1)`: en la tabla conjunta real vale $2/8=0.25$, pero el producto de marginales da $P(Y_1=2)\cdot P(Y_2=1) = 0.375 \times 0.5 = 0.1875$ — no coinciden.

::: {.callout-important}

Esto confirma que $Y_1$ y $Y_2$ **no son independientes**: saber en qué tiro salió la primera cara determina información parcial sobre el número total de caras, y viceversa.

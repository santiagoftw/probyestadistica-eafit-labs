⚡ Laboratorio 1 — Coordinación de área Estadística

Este es el laboratorio real del curso (Semanas 2 y 3), con el dataset oficial BaseLaboratorio1.csv: producción anual de energía solar, eólica, hidráulica y otras renovables, en 10 países, entre 2000 y 2023 (240 observaciones). Es el mismo laboratorio que resolverás para el Taller 1.

NoteAntes de empezar

Descarga BaseLaboratorio1.csv y guárdalo donde puedas encontrarlo. Abajo tienes cuatro formas de importarlo — elige la que corresponda a tu entorno de trabajo.

Bloque 0 · Cómo importar los datos

Importar bien el archivo es el primer obstáculo real de cualquier laboratorio. Estas son las cuatro opciones, de la más recomendada a la más manual:

  • Opción A · Ruta relativa (proyecto)
  • Opción B · Posit Cloud
  • Opción C · Fijar el directorio con setwd()
  • Opción D · Selección interactiva

Si trabajas dentro de un proyecto de RStudio (o clonaste el repositorio del curso), y el CSV está en una subcarpeta data/, basta con la ruta relativa:

datos <- read.csv("data/BaseLaboratorio1.csv")

Es la opción más portable: funciona igual en cualquier computador que tenga la misma estructura de carpetas. Requisito: el directorio de trabajo debe ser la raíz del proyecto (verifícalo con getwd()).

En Posit Cloud, los archivos que subes quedan en /cloud/project/. Sube el CSV con el botón “Upload” del panel Files, y luego:

datos <- read.csv("/cloud/project/BaseLaboratorio1.csv")

Esta es exactamente la ruta que usa la solución oficial del laboratorio del curso.

Puedes indicarle a R en qué carpeta buscar los archivos con setwd(), y después leer con el nombre del archivo solamente:

setwd("C:/Users/tu_usuario/Documents/estadistica")  # Windows
# setwd("/Users/tu_usuario/Documents/estadistica")  # Mac
datos <- read.csv("BaseLaboratorio1.csv")

Advertencia: la ruta depende de cómo esté organizado tu computador — un script con setwd() de rutas absolutas no funcionará en el computador de tu compañero. Úsalo para trabajo personal, no para scripts que vayas a compartir.

Si no quieres escribir ninguna ruta, file.choose() abre una ventana para navegar hasta el archivo:

datos <- read.csv(file.choose())

Cómodo para una sesión rápida, pero no reproducible: quien corra tu script tendrá que buscar el archivo a mano cada vez. Evítalo en trabajos entregables.

ImportantLos argumentos de read.csv() que debes conocer

read.csv() asume separador de columnas , y punto decimal .. Si tu archivo viene de un Excel en español (separador ; y decimal ,), esos supuestos fallan y debes declararlos explícitamente:

datos <- read.table("archivo.csv", header = TRUE, sep = ";", dec = ",")
  • header = TRUE: la primera fila trae los nombres de las columnas.
  • sep: el carácter que separa columnas ("," o ";").
  • dec: el carácter decimal ("." o ",").

De hecho, read.csv() es solo un atajo de read.table() con sep = "," y header = TRUE ya predefinidos. Si al importar ves una sola columna gigante con todo pegado, casi siempre el problema es el sep.

Verifica siempre la importación antes de analizar — estas dos líneas te ahorran horas de errores silenciosos:

Ítem 3 — Clasificar las variables

Enunciado: clasifique las variables entre categóricas y cuantitativas. Para las categóricas, diga si son nominales u ordinales; para las cuantitativas, si son discretas o continuas.

  • Tu turno
  • Solución oficial

Antes de ver la solución oficial, clasifica cada una de las 7 columnas usando lo aprendido en el Tema 1.

El dataset tiene 7 variables. Dos son categóricas: Year y Country; el resto son cuantitativas continuas, asociadas a la producción anual de energía: SolarEnergy, WindEnergy, HydroEnergy, OtherRenewableEnergy, TotalRenewableEnergy. Hay 240 registros: 24 por país (10 países × 24 años, del 2000 al 2023).

Nota de rigor: Year se guarda como int en R, pero estadísticamente es más apropiado tratarla como variable ordinal (o incluso como índice temporal) que como cuantitativa de razón — no tiene sentido, por ejemplo, promediar años. Country es claramente nominal: no hay orden natural entre países.

Ítem 6 — Comparar distribuciones de tres tipos de energía

Enunciado: compare las distribuciones de la producción anual de energía solar, eólica e hidráulica. Se muestra en las dos versiones (R base y ggplot2) — el mensaje estadístico es el mismo; elige la herramienta según el contexto.

  • Con R base
  • Con ggplot2
Code 
hist(datos$SolarEnergy, main = "SolarEnergy", col = "#004B85", border = "white")
hist(datos$WindEnergy, main = "WindEnergy", col = "#FFB903", border = "white")
hist(datos$HydroEnergy, main = "HydroEnergy", col = "#4B8BC2", border = "white")

También puedes ponerlos en una sola fila con par(mfrow = c(1, 3)) antes de los tres hist() — es la técnica clásica de R base para paneles múltiples (recuerda restaurar con par(mfrow = c(1, 1)) al final).

En ggplot2 los paneles se logran reorganizando los datos a formato “largo” y usando facet_wrap() — una sola instrucción genera los tres histogramas con ejes comparables:

Code 
library(tidyverse)

datos |>
  pivot_longer(cols = c(SolarEnergy, WindEnergy, HydroEnergy),
               names_to = "Fuente", values_to = "Produccion") |>
  ggplot(aes(x = Produccion, fill = Fuente)) +
  geom_histogram(color = "white") +
  facet_wrap(~ Fuente, scales = "free_x") +
  scale_fill_manual(values = c("#4B8BC2", "#004B85", "#FFB903")) +
  theme_bw() +
  theme(legend.position = "none")

Ítem 7 — Histogramas comparados por país

Enunciado: presente la distribución de la energía solar diferenciando por país.

  • Con ggplot2 (superpuestos)
  • Con ggplot2 (facetas — más legible)
  • Con R base (boxplots por grupo)
Code 
ggplot(datos, aes(x = SolarEnergy, color = Country)) +
  geom_histogram(fill = "white", alpha = 0.5, position = "identity") +
  theme_bw() + xlab("Energía Solar") + ylab("Frecuencia")

Con 10 países superpuestos, el gráfico anterior se satura. Las facetas separan cada país en su propio panel:

Code 
ggplot(datos, aes(x = SolarEnergy)) +
  geom_histogram(fill = "#004B85", color = "white", bins = 12) +
  facet_wrap(~ Country, ncol = 5) +
  theme_bw() + xlab("Energía Solar") + ylab("Frecuencia")

R base no tiene facetas fáciles, pero boxplot() con fórmula variable ~ grupo compara los 10 países en un solo gráfico:

Code 
boxplot(SolarEnergy ~ Country, data = datos, col = "#4B8BC2",
        las = 2, xlab = "", ylab = "Energía Solar",
        main = "Producción solar por país")
Tip💡 Truco de interpretación

Cuando compares una variable entre muchos grupos, los boxplots lado a lado suelen comunicar más que los histogramas superpuestos: cada caja resume mediana, dispersión y atípicos de su grupo sin que las barras se tapen entre sí (Tema 6). Ver más trucos →

Enunciado: calcule el coeficiente de variación para SolarEnergy, WindEnergy, HydroEnergy, OtherRenewableEnergy. ¿Qué puede concluir?

Code 
sapply(datos[, 3:6], function(x) sd(x) / mean(x))
         SolarEnergy           WindEnergy          HydroEnergy 
           0.5130953            0.4375286            0.4644157 
OtherRenewableEnergy 
           0.4473997
NoteInterpretación

Compara los cuatro coeficientes de variación: la fuente con el CV más alto es, en términos relativos (no en unidades absolutas), la más variable entre países y años. Nota que TotalRenewableEnergy no aparece aquí — al sumar las cuatro fuentes, la variabilidad relativa tiende a “promediarse” y suele quedar más baja que la de cada fuente individual (puedes verificarlo agregando esa columna al sapply() de arriba).

ImportantCorrección de una atribución errónea

Una versión anterior de este material citaba de memoria un valor de CV para WindEnergy que en realidad correspondía a OtherRenewableEnergy en la tabla original del laboratorio (ambos están cerca de 0.45, lo cual facilitó el error). La lección: cuando tengas los datos reales disponibles, como aquí, calcula el número tú mismo en vez de citarlo de memoria — es exactamente el tipo de error que se evita ejecutando el código en vez de solo leyendo un resultado reportado en otro lado.

Ítem 12 — Rango intercuartil, interdecil e interpercentil

Enunciado: para TotalRenewableEnergy, calcule: - Rango intercuartil: \(RIQ = P_{75} - P_{25}\) - Rango interdecil: \(RID = P_{90} - P_{10}\) - Rango interpercentil: \(RIP = P_{99} - P_{1}\) - Sus respectivas “desviaciones”: \(RIQ/2\), \(RID/8\), \(RIP/98\)

Code 
RIQ <- quantile(datos$TotalRenewableEnergy, 0.75) - quantile(datos$TotalRenewableEnergy, 0.25)
RID <- quantile(datos$TotalRenewableEnergy, 0.90) - quantile(datos$TotalRenewableEnergy, 0.10)
RIP <- quantile(datos$TotalRenewableEnergy, 0.99) - quantile(datos$TotalRenewableEnergy, 0.01)

Tip💡 Truco de interpretación

Estas tres “desviaciones” son generalizaciones de la misma idea que el RIC del Tema 6, pero usando distintas proporciones centrales de los datos (50%, 80%, 98%). Todas son medidas de dispersión robustas frente a valores atípicos — a diferencia de la desviación estándar, que sí les da peso completo. Ver más trucos →

🗂️ Cierre del laboratorio

  • La clasificación correcta de variables es la base de cualquier análisis descriptivo correcto — un error aquí invalida todo lo que sigue.
  • Comparar media y mediana es la forma más rápida de detectar asimetría antes de graficar nada.
  • El coeficiente de variación permite comparar la dispersión relativa entre las 4 fuentes de energía, aunque tengan escalas de producción distintas.
  • Las medidas basadas en cuantiles (RIC, RID, RIP) son robustas ante atípicos — útiles cuando, como aquí, los datos vienen de países con economías y capacidades energéticas muy distintas entre sí.

## Los argumentos de `read.csv()` que debes conocer
`read.csv()` asume separador de columnas `,` y punto decimal `.`. Si tu archivo viene de un Excel en español (separador `;` y decimal `,`), esos supuestos fallan y debes declararlos explícitamente:

## Ítem 11 — Coeficiente de variación

**Enunciado:** calcule el coeficiente de variación para `SolarEnergy`, `WindEnergy`, `HydroEnergy`, `OtherRenewableEnergy`. ¿Qué puede concluir?

```{r}
sapply(datos[, 3:6], function(x) sd(x) / mean(x))
```

::: {.callout-note}
## Interpretación
Compara los cuatro coeficientes de variación: la fuente con el CV más alto es, en términos **relativos** (no en unidades absolutas), la más variable entre países y años. Nota que `TotalRenewableEnergy` no aparece aquí — al sumar las cuatro fuentes, la variabilidad relativa tiende a "promediarse" y suele quedar más baja que la de cada fuente individual (puedes verificarlo agregando esa columna al `sapply()` de arriba).
:::

::: {.callout-important}
## Corrección de una atribución errónea
Una versión anterior de este material citaba de memoria un valor de CV para `WindEnergy` que en realidad correspondía a `OtherRenewableEnergy` en la tabla original del laboratorio (ambos están cerca de 0.45, lo cual facilitó el error). La lección: **cuando tengas los datos reales disponibles, como aquí, calcula el número tú mismo en vez de citarlo de memoria** — es exactamente el tipo de error que se evita ejecutando el código en vez de solo leyendo un resultado reportado en otro lado.
:::

## Ítem 12 — Rango intercuartil, interdecil e interpercentil

**Enunciado:** para `TotalRenewableEnergy`, calcule:
- Rango intercuartil: $RIQ = P_{75} - P_{25}$
- Rango interdecil: $RID = P_{90} - P_{10}$
- Rango interpercentil: $RIP = P_{99} - P_{1}$
- Sus respectivas "desviaciones": $RIQ/2$, $RID/8$, $RIP/98$

```{r}
RIQ <- quantile(datos$TotalRenewableEnergy, 0.75) - quantile(datos$TotalRenewableEnergy, 0.25)
RID <- quantile(datos$TotalRenewableEnergy, 0.90) - quantile(datos$TotalRenewableEnergy, 0.10)
RIP <- quantile(datos$TotalRenewableEnergy, 0.99) - quantile(datos$TotalRenewableEnergy, 0.01)

RIQ
RID
RIP

RIQ / 2   # desviación intercuartil
RID / 8   # desviación interdecil
RIP / 98  # desviación interpercentil
```

::: {.callout-tip}
## 💡 Truco de interpretación
Estas tres "desviaciones" son generalizaciones de la misma idea que el RIC del Tema 6, pero usando distintas proporciones centrales de los datos (50%, 80%, 98%). Todas son medidas de dispersión **robustas** frente a valores atípicos — a diferencia de la desviación estándar, que sí les da peso completo. [Ver más trucos →](../recursos.qmd)
:::

🌱 ¿Cuántas plantas necesito para poder confiar en el resultado?

Antes de montar un experimento, una de las preguntas más caras de responder mal es: ¿cuántas repeticiones por tratamiento necesito? Muy pocas, y aunque el efecto real exista, el experimento no tendrá poder estadístico para detectarlo. Muy muchas, y se desperdician tiempo, insumos y — en experimentos con plantas de crecimiento lento — años de espera. Este es un caso real de cómo responder esa pregunta antes de sembrar una sola planta, usando la potencia estadística de un ANOVA.

Contexto: crecimiento de boldo bajo distintos riegos

Un proyecto de reforestación y restauración ecológica en la zona central de Chile evalúa el crecimiento acumulado en altura de árboles jóvenes de boldo (Peumus boldus) sometidos a diferentes regímenes de riego controlado. Como el boldo es un árbol nativo de crecimiento lento, las diferencias entre tratamientos se miden a largo plazo — lo que hace especialmente costoso equivocarse en el tamaño de muestra.

Se definen \(k=4\) grupos experimentales (tratamientos de riego), con las siguientes medias esperadas de crecimiento (en metros) y una desviación estándar común estimada a partir de la variabilidad histórica de la estación forestal:

  • Medias de los tratamientos: \(\mu_1=1.84\) m, \(\mu_2=2.22\) m, \(\mu_3=2.51\) m, \(\mu_4=3.21\) m.
  • Desviación estándar común (\(\sigma\)): 0.86 m.
  • Parámetros de la prueba: nivel de significancia \(\alpha=0.05\) y potencia estadística requerida \(1-\beta=0.80\).

La pregunta del investigador: ¿cuál es la cantidad mínima de muestras por tratamiento que necesita para alcanzar una potencia del experimento superior al 80%?

Paso a paso del cálculo analítico

Paso A — Media global (\(\mu\))

\[\mu = \frac{\mu_1+\mu_2+\mu_3+\mu_4}{4} = \frac{1.84+2.22+2.51+3.21}{4} = 2.445\text{ m}\]

Paso B — Variabilidad entre medias (\(\sigma_m^2\))

\[\sigma_m^2 = \frac{\sum_{i=1}^{k}(\mu_i-\mu)^2}{k}\]

Desglosando cada término:

Tratamiento \((\mu_i-\mu)^2\)
1 \((1.84-2.445)^2 = 0.366025\)
2 \((2.22-2.445)^2 = 0.050625\)
3 \((2.51-2.445)^2 = 0.004225\)
4 \((3.21-2.445)^2 = 0.585225\)

\[\sigma_m^2 = \frac{0.366025+0.050625+0.004225+0.585225}{4} = \frac{1.0061}{4} \approx 0.2515\text{ m}^2\]

\[\sigma_m = \sqrt{0.251525} \approx 0.5015\text{ m}\]

Paso C — Tamaño del efecto (\(f\) de Cohen)

El tamaño del efecto \(f\) para ANOVA es la proporción entre la variabilidad de las medias y el error residual común:

\[f = \frac{\sigma_m}{\sigma} = \frac{0.5015}{0.86} \approx 0.583\]

Según los umbrales de Cohen, \(f > 0.40\) representa un tamaño de efecto grande — las diferencias entre tratamientos son sustanciales frente a la dispersión residual.

Paso D — Grados de libertad y valor crítico

Para un tamaño muestral de prueba \(n=10\) plantas por tratamiento y \(k=4\) grupos (\(N=40\) unidades experimentales en total):

\[gl_1 = k-1 = 3 \qquad gl_2 = k(n-1) = 4(9) = 36\]

\[\mathcal{F}_{0.05,\,3,\,36} = 2.866\]

El parámetro de no centralidad \(\lambda\)

\[\lambda = n\cdot k\cdot f^2 = 10\cdot4\cdot0.583^2 \approx 13.60\]

\(\lambda\) no es un punto en el gráfico, sino un factor que empuja y deforma toda la curva \(\mathcal{F}\) hacia la derecha. Mientras que la distribución \(\mathcal{F}\) central se concentra cerca de 1, la curva no central con \(\lambda\approx13.6\) tiene su punto más alto alrededor de 4.3.

Code 
x <- seq(0, 16, length.out = 400)
f_central    <- df(x, df1 = 3, df2 = 36)
f_no_central <- df(x, df1 = 3, df2 = 36, ncp = 13.60)
f_crit <- 2.866

plot(x, f_central, type = "l", col = "#004B85", lwd = 2,
     ylim = c(0, max(f_central, f_no_central)),
     xlab = "Valor de F", ylab = "Densidad",
     main = "Distribuciones F central y no central")
lines(x, f_no_central, col = "#D9534F", lwd = 2)
abline(v = f_crit, lty = 2)

# Sombrear la región de potencia (F > Fcrit bajo la no central)
x_sombra <- x[x >= f_crit]
y_sombra <- df(x_sombra, df1 = 3, df2 = 36, ncp = 13.60)
polygon(c(f_crit, x_sombra, max(x_sombra)), c(0, y_sombra, 0),
        col = rgb(0.85, 0.33, 0.31, 0.3), border = NA)

legend("topright", legend = c("F central (λ=0)", "F no central (λ≈13.6)", "F crítico = 2.866"),
       col = c("#004B85", "#D9534F", "black"), lty = c(1,1,2), lwd = c(2,2,1), bty = "n")

Cálculo de la potencia

La potencia es la probabilidad de que el valor \(\mathcal{F}\) observado exceda el valor crítico, bajo la distribución \(\mathcal{F}\) no central con el \(\lambda\) calculado:

\[P(\mathcal{F} > \mathcal{F}_{\alpha,\,gl_1,\,gl_2}) \quad\text{donde}\quad \mathcal{F}\sim\mathcal{F}_{gl_1,gl_2,\lambda}\]

Resolver la integral analíticamente es complicado, así que se usa R para asegurar el resultado:

Code 
# Cálculo de la potencia estadística (1 - beta)
pf(2.866, df1 = 3, df2 = 36, ncp = 13.605, lower.tail = FALSE)
[1] 0.8466995

\(P(\mathcal{F}>2.866) \approx 0.8467\). Con \(n=10\) réplicas por tratamiento, la potencia del experimento es de aproximadamente 84.67% — supera el 80% requerido.

Análisis de sensibilidad: ¿y si n fuera distinto?

Repitiendo el cálculo para \(n=2,3,\dots,15\) (manteniendo \(f\), \(\alpha\) y \(k\) fijos), se obtiene cómo cambia la potencia con el tamaño de muestra:

Code 
f_cohen <- 0.5832
k <- 4
alpha <- 0.05

n_vals <- 2:15
resultados <- data.frame(n = n_vals)
resultados$gl1 <- k - 1
resultados$gl2 <- k * (resultados$n - 1)
resultados$F_critico <- qf(1 - alpha, df1 = resultados$gl1, df2 = resultados$gl2)
resultados$lambda <- resultados$n * k * f_cohen^2
resultados$potencia <- mapply(function(fc, gl1, gl2, lam) {
  pf(fc, df1 = gl1, df2 = gl2, ncp = lam, lower.tail = FALSE)
}, resultados$F_critico, resultados$gl1, resultados$gl2, resultados$lambda)

round(resultados[, c("n","gl1","gl2","F_critico","lambda","potencia")], 4)

NoteLo que deberías notar

La potencia cruza el umbral del 80% en algún punto entre \(n=9\) (≈79.7%) y \(n=10\) (≈84.7%) — es decir, \(n=10\) es el primer tamaño de muestra entero que garantiza superar el 80% requerido. Con \(n=9\), el experimento se quedaría (por poco) por debajo del objetivo.

Interpretación y conclusión

¿Qué significa 84.67%? Si el experimento se repitiera muchas veces bajo las mismas condiciones de variabilidad (\(\sigma=0.86\) m) y con los mismos efectos esperados (\(f=0.58\)), el 84.67% de las veces se detectaría correctamente que al menos un tratamiento de riego es diferente de los demás.

El complemento es el Error tipo II (\(\beta \approx 15.33\%\)): la probabilidad de cometer un falso negativo, es decir, de concluir que los tratamientos no son diferentes cuando en realidad sí lo son.

Conclusión: el tamaño muestral de \(n=10\) réplicas por grupo (\(N=40\) en total) resulta óptimo al alcanzar una potencia del 84.67% (\(\alpha=0.05\)), superando el objetivo del 80% fijado a priori y acotando el Error Tipo II a \(\beta\approx0.1533\). Esto garantiza la sensibilidad necesaria para detectar diferencias en el crecimiento del boldo sin acudir a un sobremuestreo innecesario — limitar la muestra a \(N=40\) en vez de, por ejemplo, \(N=60\) (n=15, con 96.8% de potencia) reduce costos de insumos, horas de medición en terreno y complejidad logística en zonas de difícil acceso.

Tip💡 Truco de interpretación

La potencia no sigue creciendo de forma lineal con \(n\): entre \(n=2\) y \(n=8\) gana cerca de 10 puntos porcentuales por cada réplica adicional, pero entre \(n=10\) y \(n=15\) la ganancia por réplica ya es de apenas 2-3 puntos. Esta forma de “rendimientos decrecientes” es la razón por la que casi siempre existe un tamaño de muestra donde conviene detenerse — seguir aumentando \(n\) más allá de ese punto cuesta recursos por una ganancia de potencia cada vez más pequeña.

Verificación de los cálculos de esta página

Todos los valores numéricos de esta página se verificaron de forma independiente (Python: scipy.stats.f y scipy.stats.ncf) antes de publicarse, siguiendo el mismo criterio de rigor que el resto del curso. No se encontraron errores: la media global, \(\sigma_m\), \(f\) de Cohen, \(\lambda\), el valor crítico \(\mathcal{F}\) y la potencia para cada \(n\) del análisis de sensibilidad coinciden con el material original.

```{r}
points(10, resultados$potencia[resultados$n == 10] * 100, pch = 19, col = "#004B85", cex = 1.5)
```

::: {.callout-note}
## Lo que deberías notar
La potencia cruza el umbral del 80% en algún punto entre $n=9$ (≈79.7%) y $n=10$ (≈84.7%) — es decir, **$n=10$ es el primer tamaño de muestra entero que garantiza superar el 80% requerido**. Con $n=9$, el experimento se quedaría (por poco) por debajo del objetivo.
:::

## Interpretación y conclusión

**¿Qué significa 84.67%?** Si el experimento se repitiera muchas veces bajo las mismas condiciones de variabilidad ($\sigma=0.86$ m) y con los mismos efectos esperados ($f=0.58$), el 84.67% de las veces se detectaría correctamente que al menos un tratamiento de riego es diferente de los demás.

El complemento es el **Error tipo II** ($\beta \approx 15.33\%$): la probabilidad de cometer un falso negativo, es decir, de concluir que los tratamientos no son diferentes cuando en realidad sí lo son.

**Conclusión:** el tamaño muestral de $n=10$ réplicas por grupo ($N=40$ en total) resulta óptimo al alcanzar una potencia del 84.67% ($\alpha=0.05$), superando el objetivo del 80% fijado a priori y acotando el Error Tipo II a $\beta\approx0.1533$. Esto garantiza la sensibilidad necesaria para detectar diferencias en el crecimiento del boldo sin acudir a un sobremuestreo innecesario — limitar la muestra a $N=40$ en vez de, por ejemplo, $N=60$ (n=15, con 96.8% de potencia) reduce costos de insumos, horas de medición en terreno y complejidad logística en zonas de difícil acceso.

::: {.callout-tip}
## 💡 Truco de interpretación
La potencia no sigue creciendo de forma lineal con $n$: entre $n=2$ y $n=8$ gana cerca de 10 puntos porcentuales por cada réplica adicional, pero entre $n=10$ y $n=15$ la ganancia por réplica ya es de apenas 2-3 puntos. Esta forma de "rendimientos decrecientes" es la razón por la que casi siempre existe un tamaño de muestra donde conviene detenerse — seguir aumentando $n$ más allá de ese punto cuesta recursos por una ganancia de potencia cada vez más pequeña.
:::
